# trk! はじめてセット（r8）

**落とすのはこのファイル 1つだけ。** 見本 4 枚・目録・見本パック・書体パック 5 本・組み合わせの束と縮刷版をまとめた **約 8.0 MB** のセットです。
**`.zip` と `.stlib` は中身が同じ**（同じバイト列・同じ sha256）です。**trk235（2026-11-01）以降は `.stlib` をそのまま選ぶだけ**で入ります。

> r6 から、セットは **2 つ**に分かれました。
> - **はじめてセット**（このリリース・約 8.0 MB）… まず試す人向け。見本＋目録＋書体 5 本
> - **書体セット（全部）**（`font-set`）… 書体パック 29 本・42 ウェイト。はじめてセットの 5 本も入っています（重なっても、すでに入っているパックはアプリが飛ばします）
>
> 1 本だけ欲しいときは、このセットを落とさずに `gallery/fonts.html`／`gallery/packs.html` の「⬇ .stpack」からどうぞ。

## 手順

1. ファイルを落とす — **trk235 以降のアプリなら `.stlib` をそのまま選ぶだけ**（展開は要りません）
   （設定 → 📦 カスタムパック → 📚 目録から入れる → **📦 セット（.stlib / .zip）を選ぶ**）。それより前は `.zip` を落として**展開**
2. `gallery/all-skins.html`（見た目）・`gallery/fonts.html`（書体を選ぶ）・`gallery/pairings.html`（**書体の組み合わせ 14 組と、役ごとの設定の試作**）をダブルクリックで開く（オフラインOK）
3. trk!（trk231 以降）で **設定 → 📦 カスタムパック → 📚 目録から入れる → 📥 まとめて入れる** を押し、
   展開した中の **`catalog/index.json` と `packs/`・`font-packs/` の `.stpack` をまとめて選ぶ**

- 入れる前に **大きさ → sha256** を照合します。目録と違うものは入りません
- すでに入っているパックは入れ直しません。入れたあとは一覧の行の「使う」で適用できます
- **trk232 以降**：書体パックの「使う」で**本文の書体**も変わります（外すと元に戻ります）
- **trk233 以降**：「🔤 同梱の書体」の中の **「📄 ライセンス全文を読む」** で、`fonts/OFL.txt` の全文が読めます
- 目録の `version` と入っているパックの `release` が違うと、一覧に **「更新あり（1.0.0 → 1.1.0）」** が出ます
- trk230 の場合は「📚 目録（index.json）を選ぶ」→ 行ごとに「この .stpack を選ぶ」
