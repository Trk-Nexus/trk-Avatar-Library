# re-modern 作品ファイル：制作者の準備とローカル事前確認

この文書とツールは、独立制作者が作品を試し、利用者に説明するための**任意の制作補助**です。新たな利用規約、ライセンス、公式認定、登録条件やPWA側の仕様変更ではありません。ピクセル・コンソールは作品案として承認済みですが、正式登録・公開・フォントの最終採用は未了です。正式台帳は空のままです。

## 1. まず境界を知る

固定PWA trk320 PR #109 の head [`8531b4e206dd79adffcad3782fce3e7dd3521d7f`](https://github.com/Trk-Nexus/trk-PWA/commit/8531b4e206dd79adffcad3782fce3e7dd3521d7f) の作品用受け口を対象にしています。**これはPWA mainの版とは限りません。** 対象版が変われば再照合が必要です。PWA main `95baac2fb632d332994d6885e4a4442bcd0ea882`（trk323）でも対象4ファイルのハッシュが同一と確認し、合成テスト6件が通過しました。出力の `pwaRef` は引き続き**規則の基準版trk320**であり、指定したcheckoutのcommitを証明しません。

- 作品用 `.stpack` はZIP。`pack.json` と、追加する場合はルート直下の `LICENSE`／`README`（拡張子なし、`.txt`、`.md`、大文字・小文字を区別しない）を用います。`pack.json` 自体は小文字の正確な名前。入れ子の通常ファイルや `LICENSE-OFL.txt`、`README.js`、画像・書体は作品用経路では拒否されます。ZIPのディレクトリや `__MACOSX/` の扱いなどはPWA側に固有の規則があり、この道具もそれを使用します。一般のカスタムパックや、題字書体の個別導入とは**別の受け口**です。
- 作品ZIPは最大 **256 KiB**、展開後の `pack.json` は最大 **32 KiB**。端末に保存できる作品数は最大20件ですが、この事前確認は端末の件数や空き容量を読みません。
- `pack.json` の書式名 `shadow-taiko-pack`、`remodern.version: 1`、`trk-re-modern-` で始まるID、作品名・ライセンス、領域と色などはPWAが検証します。許可された題字指定は `system`／`dotgothic` であり、題字拡張候補ID `dotneo`／`galmuri`／`press` とは別です。未知項目は捨てられることがあります。「検査が通った」ことは記載したすべてが採用される意味ではありません。
- 作品連携の画面や限定適用は未実装です。作品ファイルを読むことと、導入・選択・表示・解除は別。未登録作品への表示にはPWAの既定や開発用設定の制約があります。利用者の既存設定を変更せずに確認できる隔離環境で実際のPWAの仕様を確かめてください。

例として、制作者自身の値と権利を確認したうえで編集する最小の**構造例**です。作品の完成品や利用許諾の表明ではありません。

```json
{
  "format": "shadow-taiko-pack",
  "version": 1,
  "name": "作品名",
  "author": "制作者名",
  "license": "制作者が確認した条件を記入",
  "remodern": {
    "version": 1,
    "id": "trk-re-modern-example",
    "regions": ["common"],
    "colors": { "stage": "#10151a" }
  }
}
```

登録IDの一意性、書体の字形・表示・対象領域や実際の色の十分さは、この例や事前確認では判断できません。

## 2. ローカル事前確認（任意）

Node 22、Avatar Library、信頼できる固定PWAのソースを用意して実行します。ネットワーク通信、PWAストレージへの保存、書換え、インストール、抽出ファイルの作成は行いません。入力は通常ファイルのみ、先頭から上限＋1バイトまで読みます。PWAの作品検証とZIP実装を**そのまま読み込む**ため、信頼できるチェックアウトを指定してください。4つの対象ソースのSHA-256が固定版と違う場合は停止します。hash照合は信頼された値との一致であり、作者認証・安全・権利の証明ではありません。

```sh
TRK_PWA_320=/path/to/trusted-pwa \
  node tools/check-re-modern-work-pack.mjs /path/to/your-work.stpack
```

JSONの `ok: true` は、固定版の**ZIP読取・名前・pack.jsonの一部条件**をこの環境で通ったことを示します。`work` はPWAが抽出・整形する値、`possiblyIgnoredFields` は代表的な未知項目の注意です。たとえば通常の `pack.json` 先頭の `version` は作品抽出では参照されず警告に含まれます（`remodern.version` とは別）。警告は拒否ではありません。文字列の整形・切り詰め、未知のネストや配列等のすべての差異を検出するものではないので、元の意図と `work` を照合してください。`ok: false` は段階と理由を返します。終了コードは0＝事前確認通過、1＝検査対象の拒否、2＝入力・固定PWA等の実行エラー。実際のPWAの画面文言や内部エラー分類と同一ではありません。

**検査しないこと**：権利・出所、公式認定、作者の真正性、安全性や悪意、文書の中身、書体ファイル、登録状態、保存件数・保存成功、設定への影響、レンダリング・オフライン更新・実機・支援技術。検査結果を「PWAで必ず導入・表示できる」「安全が保証された」と表示しないでください。第三者のパックを開くときもアプリや端末の脆弱性リスクは残ります。

### よくある理由と次の確認

| 結果 | 制作者が確認すること |
|---|---|
| `zip-size / too-large` | ZIP全体を256 KiB以下にする。容量制限の緩和は未決。 |
| `zip / invalid-or-unsupported-zip` | ZIPの破損、非対応の圧縮や重複・不正なエントリ等を確認。単一の原因と決めつけない。 |
| `entries / extra-file`、`nested-file` | 上記の作品用の名前にする。元ファイルは退避し、他の経路が必要な素材を無理に詰め込まない。 |
| `manifest / missing-pack.json`、`unreadable-or-invalid-json`、`too-large` | 正確な名前・JSON構文・32 KiB上限を確認。 |
| `manifest / bad-id`、`bad-regions`、`unknown-region`、`bad-color`、`bad-heading-font` | ID、領域、色 `#rrggbb`、許可された題字指定を確認。エラーの全種類は固定PWAのソースを参照。 |
| `preflight error` | PWAパス、対象版のハッシュ、Node環境・ファイル権限を確認。別版の結果としてごまかさない。 |

旧 `LICENSE-OFL.txt` 等を含む作品は旧版で受理されてもこの版で再インポートできないことがあります。元データと既存保存は残し、内容・ライセンスを確認してから別名で再梱包してください。再梱包はバイト列とSHA-256を変え、権利や内容の確認を代替しません。

## 3. 利用者向け説明の下書き（実装ではない）

作品の提供時に、**分かる範囲と未確認を分けて**以下を記すことを推奨します。

- 作品名、意図、作者／配布元・連絡先、版、対応PWA版と検査した環境。
- 作者による申告と、実際に検査した事実の区別。公式認定を受けていなければ誤認させない。
- 作品・書体・画像等の作者、出典・版、各ライセンス全文と再配布の条件。使う権利が不明なら同梱しない。
- 容量・対象範囲、追加取得や通信の有無、導入・適用・解除・削除で変わるもの／残るもの。未実装の機能を利用可能と記さない。
- 既知の制限、未検証、失敗時の復帰、問い合わせ先。安全や無害を保証せず、利用者が選ばない・解除する選択を尊重する。

正式な創作・頒布と利用の条件は[未発効の書面案](re-modern-research/37-independent-skin-rights-safety-draft.md)で検討中。個人を含む制作者の自由を尊重しながら、第三者の権利と既存のGPL・OFL等の条件を維持し、法務確認を経て決めます。
