# スキンを作るときの参考サイト（メモ・2026-11-02）

先方から届いた「スキンを作る際の参考サイト」を、**あとで使えるように整理して**残します。
※この環境からは GitHub・npm・PyPI の外に出られないので、**URL を開いての中身は確かめていません**。
　下の「本来のサイト」は、もらった説明から読み取れる**名前**です。**リンクを押す前に一度確かめてください**。

## 1. ゲーム UI・スキン選択画面

| もらった案内 | 本来のサイト（推定） | どこが効くか |
| --- | --- | --- |
| Game UI Database（Reddit のスレッドが貼られていました） | **gameuidatabase.com** — 商業ゲームの「スキン選択」「ショップ」「アセット一覧」の画面を数千枚集めた資料 | タブでの絞り込み・グリッドの並び・**選択中のハイライト**の作り方。`gallery/all-skins.html` の棚の並べ方 |
| osu! Skins Gallery（同じく Reddit のスレッド） | **osu.ppy.sh** のスキン配布まわり | 大量のユーザー製スキンを「グリッド」「雰囲気タグ」「対応モード」で仕分ける導線。`all-skins.html`・`packs.html` の思想に近い |

- **うちで真似したいこと**：棚は「**並べる → 絞る → 1 つ選ぶ**」の 3 手で終わる形にする。
  いまの `all-skins.html`（53 種）はグリッドとタグでそこに寄っています。**選択中のカードに色の帯**があると、指で選ぶときに迷いません
- **真似しないこと**：課金・レアリティ・ガチャの表現（この倉庫は無料で配るので、順位づけは「雰囲気」だけにする）

## 2. フォント一覧・タイポグラフィの見せ方

| もらった案内 | 本来のサイト（推定） | どこが効くか |
| --- | --- | --- |
| mojiru（もじる） | **typesquare.com**（TypeSquare） | 日本語の「丸ゴ・明朝・ポップ・ロック」の雰囲気で探す UI。`gallery/fonts.html` のタグ絞り込み |
| Google Fonts（Chrome 拡張のリポジトリが貼られていました） | **fonts.google.com**／**Google Fonts** の試し打ち | **入力した文字がその場で全書体に反映される**タイプレスタ。`gallery/pairings.html` の試作がすでにこの形 |

- **うちで真似したいこと**：`fonts.html` に**試し打ちの 1 行**（打った文字が一覧の見本に反映される）を足す。
  いまは見本が固定の文なので、**自分の曲名で見られる**と選びやすい
- 参考：雰囲気の語は、いま **16 種**（`catalog/font-tags.json`）。「丸ゴシック」でも当たるように**言い換え**を足しました（2026-11-02・§4）

## 3. レイアウトの技術（1 ファイル・Vanilla）

| もらった案内 | 本来のサイト（推定） | どこが効くか |
| --- | --- | --- |
| MDN: CSS Grid Layout | **developer.mozilla.org** の CSS Grid | `repeat(auto-fill, minmax(200px, 1fr))` の 1 行で、幅に応じて列数が変わる棚 |

- この倉庫の `gallery/*.html` は**もうこの書き方**です（`all-skins` 240px・`packs`/`fonts` 相当・`pairings` 330px）。
  1 ファイル・外部参照 0 を守るため、**フレームワークは入れません**
- スマホ幅（〜640px）では 1 列に落ちます。**カードの中身は「題字 → 本文 → 数字」の順**にしておくと、1 列でも読めます

## 4. いただいた案を、この倉庫のどこに効かせるか（案）

| 案 | 置き場所 | いつ |
| --- | --- | --- |
| 選択中のカードに帯（スキンの棚） | `gallery/all-skins.html`（`export-skin-gallery.mjs`） | r9 のあと（見本の作り直しは軽い） |
| 試し打ちの 1 行（書体の一覧） | `gallery/fonts.html`（`export-font-gallery.mjs`） | 同上。**文字を打つと全行の見本が変わる**だけなので、外部参照 0 のまま作れます |
| 「丸ゴシック」でも当たる | すでに**入れました**（`tools/export-font-gallery.mjs`・`export-pack-gallery.mjs` の `SYNONYMS`） | 2026-11-02 |
| グリッドの列数 | すでに `auto-fill` / `minmax` | 済み |

**やらないこと**：外部のフォント配信（Google Fonts など）を読みに行くこと。この倉庫は**外部参照 0** が約束です。
