## 3. 契約の確認（依頼 3）— **この形で確定してください**

`settings.typography` も `pack.json` の `skin.typography` も、**下の形で確定**でお願いします。
`gallery/pairings.html` の「書き出す」も、**もうこの形で出ます**（試作だけ違う形、を無くしました）。

```json
{
  "format": "trk-typography",
  "version": 1,
  "pairing": "shinbun",
  "preset": "roles",
  "base": 16,
  "scale": "1.25",
  "slots": {
    "display": { "family": "TrkNotoSerifJP", "weight": 700, "tracking": 0,    "leading": 1.1,  "pack": "font-packs/noto-serif-jp.stpack" },
    "heading": { "family": "TrkNotoSerifJP", "weight": 700, "tracking": 0.02, "leading": 1.35, "pack": "font-packs/noto-serif-jp.stpack" },
    "body":    { "family": "TrkZenKaku",     "weight": 400, "tracking": 0.02, "leading": 1.8,  "pack": "font-packs/zen-kaku.stpack" }
  }
}
```

**決めたこと（3 つ）**：

1. **`size` は持ちません。** 大きさは `base` と `scale` から決めます（出どころを 1 つに）。
   そちらの `typography.js` が `size` を読んでいないのに合わせました
2. **`preset` は「利用者の段階」**（`one`／`pair`／`roles`／`digits`）。**14 組そのものは `preset` を持ちません**
   ——`shinbun` は 2 役でも 5 役でも使えるので、組に段階を焼き付けると「この組は 5 役のときだけ」になってしまうためです
3. **`pack` は任意**（「どのパックに入っているか」の覚え書き）。無くても動きます。
   そちらの `sanitize()` が未知の項目を捨てるなら、`pack` は落ちても構いません

**そちらの `sanitize()` の振る舞い（未知項目を捨てる・`pairing` 不明なら `null`・`slots` の 1 役だけ差し替え可）と、
こちらの書き出しは同じ前提です。** `pack.json` の `skin.typography` の受け口を置いていただいて大丈夫です。
こちらから出すパックには、**まだ `skin.typography` を書いていません**（受け口ができたら、見本パックに 1 つだけ入れて試しましょう）。

## 4. `check-typography --json` のキー（依頼 4）— 足すだけにしました

**既存のキーは 1 つも変えていません。** 増えたのは 2 つだけです。

```json
{ "tool": "...", "version": ..., "pairings": [...], "slots": [...], "scales": [...], "presets": [...],
  "packs": 27, "fonts": 36,
  "families": ["Trk…", "…"], "familyCount": 27,
  "missingPreview": [], "warnings": [], "errors": [], "ok": true }
```

- `families` は**家族名の並び（sorted・27 件）**、`familyCount` はその数
- 意味は「この組み合わせデータが使っている家族」。**目録の全家族ではありません**（目録は 30 パック・42 ウェイト）

## 7. 見本の字数上限（おまけ・豆知識）

`pairings.html` の見本は、**書体から見本に出す字だけを抜いた woff2** を埋め込んでいます（ページを軽くするため）。
そのため、**見本文を長くすると後半が □ になります**。今回その事故が出たので、上限を決めました：

```json
"sampleLimits": { "display": 14, "heading": 20, "body": 30, "caption": 14 }
```

`check-typography` は**上限超え**と**見本の字が preview に無い**をエラーにします（対象は 4 役だけ。
`accent` と `numeral` は端末の書体なので見本を持ちません）。水増しの相談が来たら、この 4 つの数字を思い出してください。
