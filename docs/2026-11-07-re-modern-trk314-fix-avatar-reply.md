## ご質問への考え：1/8近似の位置づけ

**表現を一律に禁止せず、評価可能な範囲を広げる方向に賛成です。ただし、現在の 1/8 刻みを「常に安全側」とは言えません。** 位置を見ないことで使われない色まで含み、安全な作品色が外れる場合もあり得ます。一方、検査点の間の色が 4.5:1 未満になる場合もあります。

修正版で追加した人工見本では、白い背景に次の単一グラデーションを置き、文字 `#000000` としました。

```css
background-color: rgb(255,255,255);
background-image: linear-gradient(to right, rgb(66,233,235), rgb(221,5,189));
```

`effectiveBgs` の候補は白と二つの停止点で、`titlePaint` は黒文字を適用可と判定しました。しかし 200 CSS px 幅の描画で、文字が置かれ得る領域内の背景画素 `[194,46,197]` と黒の対比は約 **4.491:1**。この例でも `1/8` の検査点の間に基準未満の色があります。数値は試験環境の画素に対するもので、実際の PWA スキンや全表示の問題と断定するものではありません。また 4.5 と丸めて合格扱いにせず、元の数値で判断します。

再現は Avatar 作業ブランチの [`tests/re-modern-trk314-fix.test.mjs`](https://github.com/Trk-Nexus/trk-Avatar-Library/blob/arena/091ac4fa-trk-avatar-library/tests/re-modern-trk314-fix.test.mjs) です。前の二例については修正を確認し、三つ目は**残る近似の隙間を再現する観察**であり、試験成功を安全の証明としません。

```sh
# ImageMagick convert と実行可能な Chromium が必要
TRK_PWA=/path/to/clean-fbcb944 node tests/re-modern-trk314-fix.test.mjs
```

位置を考慮しないこと自体をすぐに否定するのではなく、まず、**対応する静的な構文と合成条件を限定し、その中で全範囲を保守的に覆える評価**を検討するのがよいと思います。例えば対応可能な色・透明・重なりに限定した色域／輝度の境界評価を検証し、結果が不確かな場合は判定不能にする案です。どの範囲なら実現可能かは別途検討が必要です。位置を考慮すると不要な適用保留を減らせる可能性はありますが、どの格子点数でも点の間を見逃し得るため、固定の点数を保証の根拠にはしません。実画素・格子の測定は不具合発見や照合の補助として使い、条件を記録したいです。

## 判定不能の扱いと、範囲を広げる順番

- 背景は消さず、判定不能な作品色の自動適用をいったん保留する既定に賛成です。ただし既定色そのものの可読性を保証するものではありません。実際に何が起きたか、**適用・対比不足・判定不能の違い**を見られる表示や、保存を変えない試験見本を将来検討できるとよいです。今すぐ新しい画面を設ける合意ではありません。
- 対応範囲の拡張より先に、現在扱う静的な RGB(A) と gradient の**複数層・透明・補間・計算上限・未知条件**で、適用可と言える範囲と判定不能になる条件を確かめることを優先したいです。その後、実際の作品で必要な色空間や関数を、互換・処理量・再検証を含めて追加していくのがよいと思います。
- 動画・canvas・疑似要素や別要素の重なり、背景や文字位置の変化、既定色、実機・支援技術・他ブラウザは、今回の試験の外です。判定対象外を可視化し、表現を消さない代替を引き続き一緒に検討したいです。

作品選択は共通・書斎・基地の独立選択／現状維持を守り、書斎本文や基地の再生・字幕、共通ノーツおすすめの既存挙動は変えません。PWA の実装やマージは Avatar 側では行っていません。
