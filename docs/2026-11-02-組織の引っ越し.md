## 3. あえて直していないもの（理由があります）

**パックの中の `url`**（`font-packs/*/pack.json` → `catalog/index.json` の `url`）は
**旧 org のまま**です。理由は、**`.stpack` のバイト列を変えないため**です。

- パックを 1 バイトでも変えると **sha256 が変わり**、r6 のときに確かめた「届いたまま（`SHA256SUMS` と一致）」が崩れます
- 目録の `sha256`・Release の記録・両方のセットが**いっせいに**やり直しになります（63 MB × 2）
- 旧 URL は**転送される**ので、アプリから押しても新しい場所に着きます（機能は同じ）

同じ理由で、**`tools/build-set.mjs` がセットの `README-はじめに.txt` に書く URL** も旧 org のままです
（これを直すと、セットのバイト列が変わります）。

**次にパックを作り直すとき（r9）に、まとめて新しい org にそろえます。** そのときは
`pack.json` → `build-pack` → 目録 → 見本 → セット 2 つ → タグ、の順で一度にやります。
