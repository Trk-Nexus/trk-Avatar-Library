## 3. 相談：「起動時にパックを全部読んで、どのパックの書体か分かる」形（trk238 案）

いただいた案（起動時にパックの全部を読み取れて、どのパックに入っているか分かる）に賛成です。
こちらで**アプリのいまの作りに当てはめて**、無理のない形にするとこうなります。

### 3-1. 材料はもう入っている（新しい保存は要りません）

- 入れたパックは `packDB` に **`{ id, manifest, files, size, installedAt }`** で残っています（`js/custom.js`）。
- `manifest`（＝`pack.json`）には **`fonts: [{ family, file, weight, license, licenseFile }]`** が入っています。
- いまの `listInstalledPacks()` は `id / name / author / size / active / release` だけを返していて、**書体は捨てています**。
  → **索引を作るのは「`packDB.all()` の `manifest` を 1 回なめるだけ」**で足ります。Blob（書体本体）は読まないので軽いです。

```js
/* 起動時（または 📦 の一覧を作るとき）に 1 回だけ。保存はしない
   ＝ パックを消したときに、古い索引が残らない */
async function packFontIndex() {
  const recs = await packDB.all();
  const fonts = [];
  for (const r of recs) {
    const m = r.manifest || {};
    for (const f of Array.isArray(m.fonts) ? m.fonts : []) {
      fonts.push({ family: f.family, weight: f.weight || 400,
        packId: r.id, packName: m.name || "", file: f.file,
        ...(f.note ? { note: f.note } : {}), ...(f.tags ? { tags: f.tags } : {}),
        active: r.id === packRuntime.id });
    }
  }
  return fonts;   // family / weight / packId / packName があれば「どのパックか」は言える
}
```

### 3-2. 画面（案）

設定 → 📦 カスタムパック の上に、**「🔤 入れている書体（22 本 / 15 パック）」**の表を 1 つ。

| family | 太さ | パック | ひとこと | タグ | 操作 |
| --- | --- | --- | --- | --- | --- |
| TrkZenKaku | 400 | 角ゴのお茶目 | 読みやすい角ゴ | 角ゴ・読みやすい | 使う／外す |
| TrkZenKaku | 700 | 角ゴのお茶目 | … | 角ゴ・見出し | 使う／外す |

- 並べ替えは「family」「パック名」「大きさ」、絞り込みは**雰囲気のタグ**（`catalog/font-tags.json` の 16 語と同じ語彙）。
- 「使う」は**そのパックを使う**（＝いまの `activatePack`）。書体だけ差し替えるのではなく、パックのスキンごと当てるのが今の作りに合います。

### 3-3. 「ひとこと」「タグ」はパック自身にも書けるようにしました（こちら側）

索引を作るとき、**目録（`catalog/index.json`）を読まなくても**雰囲気が分かるように、`pack.json` の `fonts[]` に
**`note`（60 文字まで）と `tags`（8 個・各 16 文字まで）を書ける**ようにしました（任意・両方あれば目録が優先ではなく**二重定義は止める**）。

- 次のパック（追加の 14 種）から、`pack.json` にも書いて出します。
- いまの 15 パックは `pack.json` を変えていません（**配った `.stpack` の sha256 を動かさない**ため）。その場合は目録の `fonts[].note` / `tags` を見てください。
- アプリ側は `sanitizeManifest` が知らない項目を捨てるだけなので、**入れても壊れません**（trk238 で読むなら 2 行）。

### 3-4. 気をつけること（こちらからの注意）

1. **1 パックの書体は 8 本まで**（アプリの `PACK_FONT_MAX`）。こちらのパックは 1〜2 本なので余裕があります。
2. **`fontWeight` の既定は 400**。`weight` が無い書体は 400 として扱ってください。
3. **family＋weight は目録全体で重複しません**（`build-catalog` の L16 が機械的に止めています）。だから索引のキーは `family|weight` で足ります。
4. 索引は**起動のたびに作り直す**のがおすすめです（保存すると、パックを消した・入れ替えたときに古い行が残ります）。16 パック×1〜2 本なら一瞬です。
5. 目録を控える方式（セットを入れたときに `catalog/index.json` の `packs[]` を保存しておく）と併用しても構いません。
   ただし**目録は「配る側の一覧」で、入っているパックとは限らない**ので、画面に出すのは「入っているパックの索引」を主にしてください。
