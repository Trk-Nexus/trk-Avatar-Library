## 2. trk254 で入ったもの(書きの生成方式)

```sh
tools/sync-typography-catalog.mjs        # 目録 → fixtures 固定 → PAIRINGS 再生成
tests/fixtures/avatar-library-typography.json        # 相手の catalog そのもの(34,194 B)

```

- 使い方: `node tools/sync-typography-catalog.mjs --from=../trk-Avatar-Library/catalog/typography.json --ref=<sha>`(または `--against=main` で GitHub から)
- 見かけ: `--check`(1 行も書き換えない / バレがあれば exit 1 と changed の組一覧)
- **値は目録から。** `packs` から `font-packs/` を載せ、それと `tracking`/`leading` を落とす、という**形式 trk246 の約束を守っています**
- 推奨 C-3 の「CI で見る」は、ここは**手元の `--check`** にしました(毎日到着すると、目録が進むたびにこの作業が発生するので)。通常回の値があるなら `--against=main --check` を workflow に1行足すとできます
