## 3. 目録の約束（アプリとの取り決め）

`catalog/index.json` は **trk230 の `js/pack-catalog.js` が読む形**に合わせました（正本：trk-PWA `docs/LIBRARY-TRK230-2026-10-31.md` §3）。

| 項目 | この倉庫の出どころ |
| --- | --- |
| `format` / `version` / `name` | 固定（`trk-avatar-library` / `1` / `trk-Avatar-Library`） |
| `packs[].name` / `author` / `file` / `sha256` / `bytes` | `.stpack` の実物から自動で入れる |
| `packs[].version` | `pack.json` の `release`（省略時 `1.0.0`） |
| `packs[].fonts[]` | `pack.json` の `fonts`（`family`・`file`・`license`・`weight`） |
| `packs[].license` / `description` / `url` | `pack.json` から（`url` は `https://` のときだけ） |

`tools/check-contract.mjs` は、この目録を **アプリの `sanitizeCatalog` にそのまま渡し**、
1 件も落とされず、値が書いたとおりに残ることを確かめます（アプリの規則が変われば、次の実行で気づけます）。

## 4. 確かめたこと（この環境で実行）

```sh
node tools/selftest.mjs                                     # 14 / 14 合格
node tools/build-catalog.mjs --check                        # 目録は最新です（2 パック）
node tools/check-contract.mjs                               # 目録はアプリの規則を通ります（2 パック）
node tools/build-pack.mjs font-packs/maru-go --check        # フォルダと .stpack が一致（sha256 93a4bb2d…）
node tools/verify-pack.mjs packs/*.stpack font-packs/*.stpack  # 2 件とも合格
node tools/preview-pack.mjs font-packs/maru-go.stpack       # 3.9 MB・書体 2・外部参照 0
node tools/export-skin-gallery.mjs --trk=../trk-PWA         # 53 種（書体 9 種）・いまの catalog/skins.json と一致
```

- 見本 HTML（`gallery/all-skins.html`）の外部参照は **0 件**（`https?://` を含まない）
- 書体パックの woff2 は **sha256 を SOURCE.json と照合**してから詰めています
  （400：`58395f89…`／700：`05b928e9…`）
- `.stpack` の生成は **無圧縮（store）で固定**しているので、Node の版が変わっても同じバイト列になります
