# 基本書体と、利用者が入手する書体の別案

2026-11-07／依頼者の提案を受けた制作方針と実装検討。**作品を正式登録・公開したこと、特定書体の権利確認や PWA の仕様合意を意味しない。** [コンセプト](../trk-re-modern-concept.md)、[ガイドライン](../trk-re-modern-guidelines.md)、[紹介書式](../trk-re-modern-introduction-template.md)にも基本方針を反映。

## 1. 目指す体験

1. **作品の基本表示**：概念に合い、当該配布方法で提供・利用できる書体を原則として一つ以上用意。利用者が作品を導入した後、第三者の書体を別に探さなくても、対応する環境・対象文字で意図した基本表示ができる経路を作る。既存の利用者設定・アクセシビリティ設定を勝手に上書きしない。
2. **任意の別案**：より表現に合うが同梱できない書体などは、条件を確認したうえで、利用者が自分で入手・利用する選択肢として紹介する。入手しなくても基本作品を利用できる。価格、利用権、対応機能は個々に違うため、無料・利用可能・導入済みと推測しない。
3. **見本**：同梱しない書体の見た目を、許可される場合に固定の画像で紹介する。画像は説明であり、書体ファイル・実際の適用・可変テキストを提供するものではない。実際に選択できる機能、表現上の提案、見本だけを明確に分ける。

作品を導入すること、外部サイトを開くこと、書体を購入・取得・インストールすること、特定の作品へ適用することは別の行為。自動購入・自動外部取得、手元の書体ファイルの無断送信・保存はしない。画像を公開できない場合は名前・権利確認済みの公式資料へのリンクと文章で説明する。

## 2. 権利の確認は用途ごと

| 行為 | 別々に確認する内容 |
| --- | --- |
| 利用者自身の入手・使用 | 正規の配布元、費用・契約の対象、個人／業務・機器数・期限等、作品での使用が許されるか。ファイルを持っていることだけで全ての利用は許可されない。 |
| 基本書体の配布 | 対象ファイルの再配布・必要なライセンスや著作権表示・改変／サブセット化・同梱形態・配布先・版とハッシュ。OFL などは実際のファイルに付属する条件を読む。 |
| アプリやブラウザへの読み込み | ローカルにインストールされた書体の利用、アプリへの手動読み込み、ウェブフォント、キャッシュ、サーバー送信・保存などは契約と技術的な権限・対応環境を別に確認。端末に入れればすべてのアプリやブラウザから使えるとは限らない。 |
| 見本画像の作成・公開・再配布 | 画像への文字の描画、ウェブ掲載・頒布、サンプル文章やロゴ・商用等の条件、画像の権利。第三者が作った画像の転載許諾も別。画像だから自由に配布できるとは限らない。 |
| 資料・説明 | 作者、公式のライセンス・入手先、参照版と確認日、画像／文字情報の出典。リンクを貼ることは再配布許諾や利用可能性の証明ではない。 |

契約や利用条件が不明なものは「未確認」として、フォントを同梱せず、画像も作成・掲載・共有しない。使用・契約の判断が難しい場合は権利者や専門家の確認を別途検討する。ここは法的助言でも、個別素材の許諾判断でもない。

## 3. 導入後に基本表示が使えるための条件

**文字の設計 → 権利 → ファイル供給 → ホスト側の読み込み・適用 → 描画・解除**を一連の体験として確かめる。

- 作品名・見出し・UI・文章をどの言語と文字範囲でその書体にするか決め、版・形式・サイズ・ハッシュとライセンスを記録する。サブセットの `cmap` は単独文字の有無の手掛かりであり、字形の適切さ・合成文字・言語全体の品質や表示を証明しない。
- 導入時に必要な基本書体を、利用を許される方法で利用可能にする。ファイルの同梱と実際のロード・対象領域への適用は別。既存環境では届かない場合は差を明記し、PWA との受け口・容量・旧版・復元を相談する。別実行環境も選択肢で、いずれも利用者の明示的な導入と範囲の説明が必要。
- 基本書体が読み込めない、文字が不足、旧版が未対応、利用者が既存の文字設定を優先、オフライン、保存・削除・更新が失敗した場合の挙動を記録する。端末の system fallback は重要だが端末ごとに異なり、**それだけで字種・表示品質を保証しない**。必要な言語範囲を満たす配布可能な追加フォールバックも候補とし、容量・権利・可読性を評価する。
- 利用者が別案を選んでも、適用範囲・現在の設定・解除後の状態を確認でき、基本表示や現状維持に戻れるように設計する。これは未実装の仕様提案で、現行の PWA に同じ操作があるとは言わない。

## 4. ピクセル・コンソールへの適用状況

| 項目 | 現状・次の確認 |
| --- | --- |
| 概念に合う基本書体候補 | DotGothic16 Regular 400 の日本語 WOFF2。作者資料・取得元・OFL 全文と実ファイルのハッシュは[棚卸し](11-dotgothic-distribution-inventory-2026-11-07.md)。候補であり、作品への正式採用・権利の最終判断はまだ。 |
| 隔離見本 | [研究見本](12-font-included-isolated-study-2026-11-07.md)では書体を実際にロードし見出しのみ切替できる。ただし初期状態は system 系、PWA 作品への導入・適用機能はない。これを作品導入後の基本表示が完成した証拠としない。 |
| 現在の4言語の作品名 | 同 WOFF2 の cmap と現行 `skin.json` の label を照合。日本語 `ピクセル・コンソール`、英語 `Pixel Console`、中国語 `像素控制台` は各文字が収録、韓国語 `픽셀 콘솔` は `픽`・`셀`・`콘`・`솔` が未収録。これは文字ごとの存在検査だけであり、中国語の字形の妥当性や他の文章・表示品質を保証しない。 |
| 次に必要 | 韓国語を含む対象文字の扱い、概念に合う・配布条件を満たす追加書体／フォールバック、実際の表示と容量を検討。本文用書体とは役割を分ける。候補の商用・別書体は調査・許諾前にファイルも画像も配布しない。 |
| 既存 PWA の受け口 | 確認時 main `4f93a69f94ec3a3c14c6ea8d1cf9c064723b43e6` の `remodern-work.js` は ZIP 256 KiB 上限、`pack.json` とルートの README／LICENSE 類以外のファイルを拒否。WOFF2 396,312 B は単体で上限を超え、現行作品形式にそのまま同梱・適用できない。従来の別の書体 pack はスキン・ノーツ等に影響し得るため、見出し限定の完成経路とはまだ言えない。 |

**韓国語の補助候補（追記）**：[NeoDunggeunmo の二書体隔離研究](15-korean-font-fallback-study-2026-11-07.md)では、作者の OFL 版を追加した見本で韓国語作品名を描画できた。選定・実装・字形レビュー・配布や PWA の受け口は未完で、既存の 256 KiB 作品形式には両書体を同梱できない。

PWA との相談や対応は、フォント込みの案の対象・権利・供給・設定・失敗時を整理してから行う。今は PWA に連絡・仕様変更を行わず、Avatar 側の検討を進める。

## 5. 次の作業と完了の目安

1. 基本書体の用途・言語ごとの文字列を決め、権利と必要容量を照合。見出し以外・全言語をこの WOFF2 が網羅すると仮定しない。
2. 必要な追加フォールバックを、概念・権利・容量・実表示で比較。任意の別案は入手・利用・画像許諾が個々に確認できてから具体化する。
3. 現状維持、作品の基本表示、任意の別案、未導入・欠字・失敗・解除を分けた隔離見本を試す。見本画像が未許諾の場合は名前と説明のみ。
4. PWA と連携する案には、実ファイル、作者・版・ライセンスと出典、容量・字種、導入と適用の境界、利用者設定・解除、互換・安全性・テスト・未確認を添える。PWA と分担を協議し、承認・実装・実機確認を別に記録する。
5. **完成の目安**は、対象範囲の表示、権利・表示条件、導入・選択・解除・失敗時の体験を検証し、利用者と必要な独立レビューで確認できたこと。正式登録・公開はその後に別判断する。
