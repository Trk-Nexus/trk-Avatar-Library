# 題字限定の書体拡張：隔離試作

2026-11-07／[二書体パックの試作](17-isolated-font-pack-candidate-2026-11-07.md)の続き。**PWA の機能ではない**。固定版 PWA に研究用 JavaScript を一時的に注入し、独立したブラウザプロファイルで成立可能性を調べた。作品の正式採用・拡張の配布・PWA の仕様合意・すべての利用者設定を守る保証ではない。

## 目的と試作の境界

現行の設定画面のパック選択は保存と有効化を一緒に行い、既存パックを切り替えて本文などにも書体を適用する。試作ではこの UI を利用するのではなく、隔離テストの中でのみ PWA の内部 `installPackFile` を呼び、研究用パックを**保存だけ**した。通常の設定画面に「保存だけ」の操作があるという意味ではない。

続いて、Avatar 側の[研究用コントローラー](pixel-console-scoped-font-study/controller.js)に、既に保存されたパックを読む関数と PWA の共通題字 `.brand h1` を明示的に渡した。作品ファイルの JavaScript を PWA が実行する仕組みではない。題字の実文字は PWA の `trk!` で、韓国語の字形試験には一時的な検査テキストを子要素として追加・削除した。書斎・基地の実装や作品紹介一覧への適用は対象外。

- 書体2ファイルと各 LICENSE が揃い、**正確なサイズと固定 SHA-256** に一致するときだけ、2つのローカル Blob を FontFace にロードしてから題字にだけ CSS クラスを追加する。パック内の任意の JavaScript・CSS・URL は読み取って実行しない。本人のデータに対して試すものではない。
- 本文の `--font` やスキン・ノーツを変更せず、一意のクラスと一時スタイル、研究用 FontFace と object URL を使う。CSS の優先度によって利用者の題字設定が上位になる場合は、それを上書きせず適用を失敗として取り消す。
- 解除は試作が作ったものだけを除去し、元の設定値を保存・書き戻さない。読み込み途中で解除された試行を無効化し、どちらかのフォントやライセンスの不備・ロード失敗なら、部分適用せずに後片付けする。
- これは単一題字・同一セッションの実験。選択状態の永続化、作品との連動、更新・削除、別タブ・同時編集、アクセス可能な設定 UI、必要なライセンスの表示はまだ実装していない。PWA の内部 API は既存の公開された利用者向け契約とは限らず、将来使える保証はない。

## 独立試験の結果

[自動試験](../../tests/re-modern-scoped-font-study.test.mjs)を、PWA main `4f93a69f94ec3a3c14c6ea8d1cf9c064723b43e6` のクリーン checkout と Chromium 133.0.6943.0 で実行。ローカル HTTP・Service Worker 無効・外部要求遮断、空のプロファイルを使用。

| 確認 | この環境での観測 |
| --- | --- |
| 既存パックとの共存 | 既存のスキン・ノーツ付き DotGothic パックを有効化した後、内部の保存 API で研究パックだけを格納。既存のアクティブ pack ID・スキン・ノーツ・本文書体は変わらなかった。研究コントローラーで題字限定の書体を有効にしても、これらは同じだった。 |
| 題字・本文 | 題字の font-family は `AvatarScopeResearchDot, AvatarScopeResearchNeo, TrkDotGothic, ...`。本文は元の `TrkDotGothic, ...` のままで、設定画面の別の見出しも変化なし。確認した2要素についての結果であり、すべての画面の保証ではない。 |
| 韓国語の実描画 | 題字に一時的に付けた `픽셀 콘솔` の4字について、Chromium DevTools は NeoDunggeunmo を実描画書体として報告した。空白は DotGothic16。実際の PWA 題字は `trk!` である点に注意。字形の正しさや他の文の表示品質は未確認。 |
| 利用者変更 | 適用中に題字のインライン書体を `serif` に変えると、それが優先され、解除後もその指定は残った。先にインライン指定がある場合は適用失敗として後片付け。適用中に PWA のスキンを `shadow` に変更した別の試験でも、解除時に新しいスキンや本文の指定を戻さなかった。 |
| 失敗と競合 | 書体拡張なし、長さが異なるライセンス、長さは合うがハッシュが異なるライセンス、2つ目の FontFace を模擬的に失敗させた条件でエラーになり、部分適用は残らなかった。取得待ち中の解除は `cancelled`。これらの後、試作の FontFace と CSS による見た目は残らず、確認した既存設定は同じだった。 |
| 再読込 | 試作の選択は意図的に保存しないため、再読込後は試作の書体は復元されない。既存パックと利用者が変更したスキンはこの条件で復元された。 |

候補パックは[研究17](17-isolated-font-pack-candidate-2026-11-07.md)の正確な材料を使い、一時出力のほかリポジトリへ WOFF2 を追加していない。再現にはその資料に示す PWA checkout と明示取得した NeoDunggeunmo のファイルが必要。

```sh
TRK_PWA=/path/to/fixed-pwa TRK_NEO_DIR=/path/to/neo-dir node tests/re-modern-scoped-font-study.test.mjs
```

実行可能な Chromium が必要。実験では設定画面の選択のほか、保存 API やスキン変更 API を使っており、すべてが実際の利用者向け UI 操作ではない。

## 完成案に向けた残り

1. **作品との契約**：どの作品のどの領域が拡張を必要とするか、導入済み・未導入・部分失敗の状態、ユーザーの承諾と設定の優先順位を決める。通常の設定棚に保存だけ・適用・解除・削除をどう見せるかは未実装。
2. **ライフサイクル**：再起動後の再検証と明示的な復元、作品／書体の更新・消去、複数の領域・作品・タブでの共有、インストール変更通知、競合・失敗・容量不足を設計する。今回の試作には自動追従・永続化・同期はない。
3. **権利情報**：両書体それぞれの出典と LICENSE／著作権表示を利用者が読めるようにする。現在のPWAパック詳細は先頭の LICENSE だけを表示するため、今回の試作では未解決。正式配布前に独立して法的条件と予約名を確認。
4. **表現とレビュー**：必要な文字列の字形、韓国語・中国語などの自然さ、サイズ・拡大・OS／ブラウザ・実機・支援技術、手動レビューを確認する。書体がロードされたことは可読性や権利を証明しない。
5. 完成候補をまとめた後に、既存の設定棚と独立した範囲指定を PWA 側と相談する。今回は PWA を変更せず、連絡も行っていない。
