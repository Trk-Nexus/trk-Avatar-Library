## 対象・読み方

- 対象 PWA：未マージ作業ブランチの `575cb075dbaf23c7f3dac3dbd60e7353f0912184`、クリーンな checkout。確認時 main は `1c939842004c61d6a3b14609d508ed856bdee2d9`（別の版）。今後の修正には別の固定版で再確認が必要。

- 状態の区別：**適用**＝作品色が指定される、**対比不足で保留**＝背景候補あり・該当色が `skipped`、**判定不能**＝`effectiveBgs` が `null`。判定不能の場合 `titlePaint` の `skipped` は空である。題字色が `null` という結果だけでは理由は区別できない。候補作成と UI での表示・通知は別の調査項目。

## A2：選曲画面を限定して調べた結果

### 方法

[実画面調査スクリプト](../../tests/re-modern-trk314-screen-investigation.test.mjs)で、固定版を一時ローカル配信し、Chromium 133 の新規プロフィールを使用。Service Worker と外部リクエストを遮断。未登録の人工作品（文字 `#e0e8ff`・アクセント `#202020`）を**隔離されたブラウザ内だけ**で保存し、開発用適用を明示的に有効化、共通領域を独立にして reload。通常の `core.applySkin(id, false)` を呼び、題字の inline 色・候補・祖先の computed style を記録した。PWA や実ユーザーの設定・作品登録は変更していない。スキン選択 UI を通した end-to-end 試験ではない。

手順を実行するには、Avatar の依存、ImageMagick `convert`、実行可能な Chromium と上記 fixed checkout が必要。

```sh
TRK_PWA=/path/to/clean-575cb075 node --test tests/re-modern-trk314-boundaries.test.mjs
TRK_PWA=/path/to/clean-575cb075 node tests/re-modern-trk314-screen-investigation.test.mjs
```

### 観察

- 実画面の祖先は `h1 → div.brand → header.head → div.card.wide → section#selectScreen → #stage → body → html`。両スキンとも題字そのものと brand・header の背景は透明。カードの背景は半透明で、その外の選曲画面には放射状の淡い光と単色背景がある。
- `shadow` のカードは `rgba(14,16,24,0.96)`、選曲画面は暗色と赤系の光。1280×900 の候補は `[14,16,24]`／`[15,16,24]`。人工作品の文字色は適用、アクセントは保留。題字枠内の左上付近の**文字のない観察点**は `[13,15,24]`。
- `daylight` のカードは `rgba(255,255,255,0.97)`、選曲画面は淡い色と赤系の光。1280×900 の候補は `[254,255,255]`／`[254,254,254]`。人工作品の文字は保留、アクセントは適用。同じ観察点は `[254,255,255]`。
- `shadow → daylight → shadow` と内部 API で切り替えた際、上記作品色の inline 状態はその時点の `titlePaint` の結果と一致した。色が保留された部分は既定値へ戻る。背景を消す操作は行っていない。**既定色の対比をこの調査が保証するわけではない。**
- 同じ二色・2スキンで viewport 390×844 も観察し、それぞれの候補・適用状態と観察点の色は上記と同じだった。これはデスクトップの headless viewport を狭めた試験で、モバイル実機ではない。
- CSS `body { zoom: 1.5 }` を直接設定した別の操作では題字枠の座標が viewport の外になり、画素は採取できなかった。これは**ブラウザの拡大操作とは異なる人工操作**で、実際の拡大表示の良否は未判定。CSS zoom 下でもスキン変更後の候補と inline 判定は取得できたが、表示が読めるかの証拠にはならない。

画素は文字ではなく背景の一点で、アンチエイリアスや全字形に対する測定ではない。人の目視、通常のブラウザ拡大、狭幅でのレイアウト操作、端末・OS・他ブラウザ・支援技術、スキン変更以外の再評価、実作品の導入・解除は未確認。スキンは2つだけで、他のスキン・画像・背景混合方法・すべての背景に一般化しない。
