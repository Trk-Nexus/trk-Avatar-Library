# ピクセル・コンソール：書体の対象・依存関係の案

2026-11-07／[進捗計画](19-remaining-roadmap-2026-11-07.md) A 節の手順1。**作品を構成するための Avatar 側の提案・研究**であり、PWA 形式・実装の確定、特定書体の正式採用、公開、各言語の表示品質や権利の最終確認ではない。利用者が承認した作品案と、下記の新たな書体の適用案は区別する。

## 入力と前提

| 入力・条件 | 内容・現在の状態 |
| --- | --- |

| 対象環境 | 確認済み PWA main [`4f93a69f94ec3a3c14c6ea8d1cf9c064723b43e6`](https://github.com/Trk-Nexus/trk-PWA/tree/4f93a69f94ec3a3c14c6ea8d1cf9c064723b43e6)。固定版における作品ZIPと汎用パックの違いは[研究16](16-font-pack-settings-shelf-design-2026-11-07.md)。将来の版では再確認する。 |

機械可読の[研究用条件表](pixel-console-font-contract.json)は上記の範囲を検証しやすくする補助データで、PWA の manifest や実装契約ではない。

## 対象と保護範囲

| 場所 | 予定・試験対象 | 選択と保護 |
| --- | --- | --- |
| 共通画面の題字 | 固定版の `.brand h1` は **`trk!`**。作品の共通領域を選び、書体の適用を利用者が明示的に選んだ場合の候補。実際の題字への採用・見た目は後の確認が必要。 | 現状維持や別作品を選んだだけで適用しない。既存の書体・アクセシビリティ等の利用者選択を尊重し、競合時は勝手に上書きせず状態を示す。 |
| 作品名 | 作品データの `label.ja/en/zh/ko` は **作品名であり、PWA 題字 `trk!` ではない**。当面は隔離見本の題字候補として確認。作品一覧や設定UIへの適用は決めていない。 | `lang` を言語に合わせる。作品を選ぶ前の一覧全体を勝手に変更しない。各言語の字形は別途人が確認。 |
| 説明文・本文・設定画面のその他の見出し | この書体拡張の適用対象外。作品の `desc` も読み物であって題字候補の確認対象ではない。 | それぞれの既存設定・端末の設定を維持。特に長文にドット書体を一律適用しない。 |
| 書斎・基地・再生・字幕・共通ノーツ | 今回の書体適用対象外。既存の作品・スキン・パックの機能を一括で停止・切替しない。 | 各領域の選択、読書本文・再生・字幕・ノーツの状態を保護。別領域で新たな使い方を考えるときは別途対象と同意を整理する。 |
| 既存のスキン・パック | 保存済みの研究用書体の読み込みと、通常のアクティブパックは独立させる方向。 | 現行の汎用パック UI で「使う」は既存アクティブパックを切り替えるため、そのままではこの条件を満たさない。独立した受け口は未実装。 |

「書体を適用しない」は**この拡張が変更しない**という意味で、利用者が既に選んでいるスキンや書体まで system 系へ強制する意味ではない。PWA の既存スタイル・作品色の対比判断を勝手に変更しない。

## 文字列とフォールバックの候補

対象候補を次の順で考える：**DotGothic16 → NeoDunggeunmo → 利用者の既存の書体スタック → 端末の system 系**。書体選択の優先・既存スタックの参照方法は未実装であり、既存の `--font` が常に system 系であるとは限らない。利用者のより優先すべき設定がある場合は、この作品の指定を適用しない選択を可能にする。

| 文字列の由来 | 言語・文字列 | 固定 WOFF2 の cmap 上の確認 | 未確認 |
| --- | --- | --- | --- |
| PWA 固定版の共通題字 | `trk!` | DotGothic16 に4種類すべて | 実画面上の見た目、重み・間隔、字形への利用者評価。 |
| 制作データ `label.ja` | 日本語 `ピクセル・コンソール` | DotGothic16 に9種類すべて | 字形の見やすさ・組版。 |
| `label.en` | 英語 `Pixel Console` | 両書体に英字を収録 | 空白の実描画・字間・見た目。 |
| `label.zh` | 中国語 `像素控制台` | DotGothic16 に5種類すべて | 地域に適した漢字の字形・読みやすさ。文字の存在と中国語書体としての妥当性は別。 |
| `label.ko` | 韓国語 `픽셀 콘솔` | DotGothic16 は4字欠き、NeoDunggeunmo に4字すべて | 韓国語話者による字形・組版・可読性。 |

[新しい固定入力の照合テスト](../../tests/re-modern-font-contract.test.mjs)は、制作データの現在の作品名と2書体それぞれの文字を検査し、上表の Dot／Neo の欠字と組み合わせの残り欠字を照合する。判定対象は単独コードポイントで、**空白を検査対象の数から除外**する。結合、言語全体、字形や適切さは検証しない。韓国語見本の実際の描画フォントは[研究18](18-scoped-font-prototype-2026-11-07.md)で別に限定確認している。

## 依存不足と既存環境：期待する状態（未実装の案）

| 入力状態・操作 | 提案する期待結果 | 現時点の証拠／未確認 |
| --- | --- | --- |
| 共通領域が現状維持、または別作品／書体不使用 | この作品による題字書体は使わない。既存設定はそのまま。 | 研究18は直接コントローラーを操作し、作品選択との結合は試していない。 |
| 作品を選択、拡張未導入 | 導入と範囲を案内。既存書体のまま代替表示し、意図した基本書体は未適用と明示。外部から自動取得しない。 | 未導入による研究試作の失敗と後片付けは研究18で確認。利用者向け案内は未実装。 |
| 拡張あり・両書体／両ライセンス検証済み・適用を選択 | 二書体を同じ操作の中でロードし、両方が成功した後に候補対象のみに適用。作品名などの範囲外は変えない。 | 単一題字の研究試作はサイズ・ハッシュ確認後に両書体をロード。PWAの UI、保存・ライセンス確認と連携した完成動作ではない。 |
| 片方のファイルやライセンスの不足・不一致、片方のロード失敗 | **部分的な作品書体に切り替えず**、適用前の利用者表示を保つ。理由と再試行・解除を示す。 | 固定バイトの不一致、模擬の2つ目の書体失敗は研究18で限定確認。UI 通知・保存失敗・全ブラウザは未確認。 |
| 必要な個別文字が両書体にない | 両書体ロード成功と対象文字の網羅は別。既存スタック・system 系へ代替し、その範囲や端末依存を説明。 | 現在の `label` 4言語には単独文字の欠字なし。対象外の文章・字形・結合は未確認。代替表示の字形は保証しない。 |
| 利用者設定が上位、適用中のスキン変更・解除 | 利用者の選択を優先し、解除は本作品が管理した資源だけを外す。適用後に利用者が変えた値を古い値に書き戻さない。 | 題字のインライン書体と1種類のスキン変更を研究18で限定確認。他の設定・同時変更は未確認。 |
| 旧PWA・未対応・拡張の更新や削除・再起動 | 未対応や欠落を明示し、既存表示を保つ。再適用は検証・ユーザー選択・復元方針に従う。 | 現行PWAに作品ごとの受け口なし。永続化、更新・削除、複数タブ、競合・通知は未設計／未検証。 |

「両方揃うまで適用しない」は、この候補における**安全側の初期案**。作品自体の導入を強制停止する意味ではなく、片方だけの使用や部分適用を将来提供できるかは、その体験・権利・設定とともに別途判断する。

## 次に進めること

1. 本案を[状態遷移・競合・復元](19-remaining-roadmap-2026-11-07.md)に落とし、作品の選択と書体の保存・適用・解除・削除を分けたテストを増やす。
2. 2つのライセンス全文と著作権表示を利用者が個別に確認する導線、配布・識別・版管理を整理。原作者資料と対象バイナリを引き続き区別する。
3. 中国語・韓国語などの字形・人手レビュー、実機・異なるブラウザ・支援技術を別途実施し、できていないものを完了扱いにしない。
4. フォント込みの完成候補をまとめてから PWA 側に設定棚・独立適用を相談する。今回、PWA への連絡・仕様変更・正式配布・正式登録は行わない。
