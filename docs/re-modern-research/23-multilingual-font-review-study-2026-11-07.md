| --- | --- | --- | --- | --- |

### 大事な違い：比較見本と製品案

この見本は CSS のフォールバックによる**表示比較のみ**で、読込失敗を通知せず、片方のロードに失敗してももう片方や端末書体が使われ得る。ロードを待つ機能や保存・適用・解除もない。研究案にある「両書体を検証・ロードしてから対象に適用し、失敗時は既存表示を維持する」と同じ動作ではない。欠字・失敗時の代替フォントは端末に依存し、文字要素が存在することだけで可読性は分からない。

## 試験の結果と範囲

[ブラウザ試験](../../tests/re-modern-multilingual-study.test.mjs)は、固定 PWA と固定書体から生成した見本を Linux sandbox の Chromium 133.0.6943.0、JavaScript 無効・Service Worker 無効で確認した。

- 制作データの4文字列・各 `lang` と、固定版題字の文字列を照合。両書体の FontFace `loaded` を確認し、Chromium DevTools から上表の各文字列に使われた書体を確認。system 系での実際の書体は端末依存で、この結果から可読性や字形の正しさを判断しない。
- 初期 system、Tab と矢印キーによるラジオの切替、本文の CSS font-family 不変、再読込後に初期選択へ戻ることを確認。指定の WOFF2 は選択まで要求されず、外部要求は試験中に観測されていない。両ライセンスのローカルリンク先のバイト列も確認。
- 両選択肢で幅 1280／390／320 CSS px、ルート文字サイズ 100%／200% の文書横 overflow なし。forced colors・動き軽減のエミュレーションで中国語・韓国語の要素は表示された。これらは**実ブラウザのズーム、実際のコントラスト・操作性・読み上げ**の確認ではない。
- 書体をそれぞれ遮断すると各 FontFace は `error`、日本語・韓国語の要素は残った。代替字形やその可読性、欠落の通知、製品案の原子的な適用は未検証。誤った Neo ファイルは既存の生成済み HTML を変更する前に拒否された。
- 異なるブラウザ・OS・実機・インストールフォント・実ズーム・支援技術・人の確認は未実施。機械試験の成功を、人手での採用判断やアクセシビリティ適合として扱わない。

## 再現

固定 PWA checkout、[研究15の手順](15-korean-font-fallback-study-2026-11-07.md#ローカルで再現する場合)で明示取得した Neo 1.601 の WOFF2・LICENSE、Node と Chromium を用意する。PWA checkout は固定 commit かつ clean が必要。ツールは既存 pack・両書体・両ライセンスのハッシュを確認し、外部取得しない。

```sh
node tools/prepare-re-modern-multilingual-study.mjs --trk=/path/to/fixed-pwa --neo-dir=/path/to/neo-dir
TRK_PWA=/path/to/fixed-pwa TRK_NEO_DIR=/path/to/neo-dir node tests/re-modern-font-contract.test.mjs
TRK_PWA=/path/to/fixed-pwa TRK_NEO_DIR=/path/to/neo-dir node tests/re-modern-multilingual-study.test.mjs
python3 -m http.server 4176 --bind 127.0.0.1 --directory dist/re-modern-multilingual-study
```

出力は Git 管理外。別の場所は `--out=/path/to/output` で指定可能で、同名の生成ファイルは上書き、無関係の古いファイルは消さない。入力検証後の複数ファイルの書き込みは原子的ではないため、正式配布物の場所を使わない。見本を外部へ配布・公開する場合は別途権利と承認が必要。
