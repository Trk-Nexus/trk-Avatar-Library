# trk-re-modern：カタログ書式と書斎・基地の展開案

2026-11-06 ／ **提案・研究用**。ユーザーがピクセル・コンソールの見本を確認し、作品紹介の共通書式、書体の明記、書斎と基地への展開という方向を提案した。以下は Avatar 側で検討した案であり、PWAへの依頼・合意・実装・公開を意味しない。

## 1. 何を形にしたか

- [研究用の一覧・検索見本](pixel-console-preview/catalog.html)：構想中のピクセル・コンソール１案だけ。名前、方向、対象領域、**見本の実使用書体と作品の候補書体**を区別し、詳細へ移動できる。JavaScript 無効時は一覧を読むことができる。検索はページ内で処理し、入力内容を保存・外部送信する処理を設けていない。候補を検索できても採用済みとは意味しない。端末やブラウザによる履歴保存等は別。
- [個別紹介の見本](pixel-console-preview/index.html)：もとの見本に書斎・基地の**未実装の構想**と書体カードを追加。実際のPWA画面を再現・操作するものではない。
- [個別作品紹介・カタログ書式 v1](../trk-re-modern-introduction-template.md)：一覧に出す情報、作品の共通説明、領域別状態、書体の出典・入手・条件・適用、検証と修正履歴を揃える。現行の作品JSONや公開ゲートは変更しない。

これらは研究用であり、登録済みの `trk-re-modern` 作品の一覧ではない。正本の台帳は空のまま。正規の一覧・詳細・検索は、作品を登録できる状態になってからガイドラインの公開経路に整える。見本のページをそのまま正式公開・量産したとは扱わない。

### 見本の限定検査

2026-11-06、Linux sandbox／headless Chromium 133.0.6943.0／Playwright Core 1.50.1 で [研究用テスト](../../tests/re-modern-catalog-prototype.test.mjs)を実行。単一項目について、候補書体名・全角英数字・複数語・日本語領域名の検索、該当なし・検索解除、JavaScript無効時の一覧表示、詳細から既存書体一覧への移動と `TrkDotGothic` 検索を確認した。検索の最中に外部リクエストは発生せず、ページを提供するローカルHTTP以外の通信は試験で遮断した。1280・390・320 CSS px とルート文字サイズ100%／200%で文書の横はみ出しなし、強制色と動き軽減のエミュレーション下で作品見出しが表示されたことを機械的に確認。複数作品・日本語のあらゆる表記ゆれ・実ブラウザズーム・読み上げ・人による見やすさ・Firefox／Safari／実機は未検証。これは正式カタログの公開確認でもアクセシビリティ適合の保証でもない。

```sh
node tests/re-modern-catalog-prototype.test.mjs
```

Chromium と開発依存が必要で、実行環境によって共有ライブラリの設定が必要。[既存の静止見本テスト](../../tests/re-modern-pixel-preview.test.mjs)も再実行した。

## 2. 書体について正式に区別する

| 何の書体か | 今回確認できること | 現状 |
|---|---|---|
| 見本の本文・大見出し | CSS `system-ui,-apple-system,"Segoe UI",sans-serif`。端末・字種ごとに実際のフォントが異なる。 | 見本で使用。外部フォントの同梱・取得なし。太さはCSS指定であり、端末の実フォント次第。 |
| 見本の英数字ラベル | 基本は `ui-monospace,monospace`。一部のラベルは `ui-monospace,SFMono-Regular,Consolas,monospace`。同名書体が端末にある保証なし。 | 見本で使用。フォントバイナリは同梱しない。 |
| 新作品の見出し候補 | DotGothic16 Regular 400、作者 Fontworks Inc.、OFL 1.1。作者上流とライセンスは[前回の一次資料](01-pixel-console.md#7-参考資料と探索の記録)を参照。 | 候補。新作品にも見本にもロードされていない。既存パックの上流リンク404、実配布物・取得元の整合、PWAで見出し限定とする方法、言語・fallback は未解決。 |
| 既存「ドットの電子音」パック | `font-packs/dotgothic.stpack` に `TrkDotGothic` として WOFF2 を同梱。書体だけでなくスキンとノーツも含む。 | 既存の別パック。使うと見た目や共通ノーツに影響し得る。新作品に書体を適用する方法として確認済みではない。 |

ローカルの[既存書体一覧](../../gallery/fonts.html)を、見本の書体カード・一覧から辿れるようにした。これは既存の書体パックを探す入口であり、新作品の書体選択・自動適用ではない。正式Pagesでの `gallery/fonts.html` の公開対象・リンク導線は本ターンに変更・確認していないため、研究用見本でのリンクを公開済みの機能として扱わない。既存 DotGothic の出典誤記は本ターンでも修正していない。OFLの同梱・ライセンス名は、出典リンクの整合や条件の再確認の代わりではない。

## 3. 固定PWAの現状：何が既にあり、何がないか

調査対象 `Trk-Nexus/trk-PWA` commit `f7b1272547f712d9a7d7a198404148457e936008`。ソースを読んだ結果であり、全UIや全組み合わせを操作した検証ではない。

### 書斎

- [study-room.css](https://github.com/Trk-Nexus/trk-PWA/blob/f7b1272547f712d9a7d7a198404148457e936008/css/study-room.css) では、書斎の開くボタンには共通 `--ui-*` を使う一方、書斎本体は固定色・固定の system 系 font 指定を多く持つ。
- [study-room.js](https://github.com/Trk-Nexus/trk-PWA/blob/f7b1272547f712d9a7d7a198404148457e936008/js/study-room.js) には読書本文の `studyPrefs.theme` と許可された `STUDY_THEMES` があり、テーマ、文字サイズ・行間・余白等を個別に扱う。画像と文章は異なる表示経路。既存の「読書本文テーマ」と将来の「書斎の外枠スキン」は同一ではない。
- したがって、共通スキンの切替で書斎のすべてが同じ作品に切り替わるとは言えない。既存の読書本文テーマや文字設定を、新しい外枠の変更で自動上書きすることは提案しない。

### 基地

- PWA の「🎥 基地」は、[media-player-mode.js](https://github.com/Trk-Nexus/trk-PWA/blob/f7b1272547f712d9a7d7a198404148457e936008/js/media-player-mode.js) が作る音楽・動画のメディアプレーヤー入口。退出、状態、動画、字幕、画中画等を含む。
- [style.css](https://github.com/Trk-Nexus/trk-PWA/blob/f7b1272547f712d9a7d7a198404148457e936008/css/style.css) に共通 `--ui-*` を使う部分と、再生表示などの固定色・装飾が混在している。現在でも共通色が一部に影響するため、「現状はまったくスキンが効かない」とは言わない。
- 基地全体について、作品ごとに独立して選び・既存状態に戻せる受け口があるとは確認できていない。映像・ジャケット・字幕・再生操作を守る設計と、PWA側の設計合意が必要。

## 4. 受け皿の設計論点（PWA側への提案案）

**共通・書斎・基地をそれぞれ独立して選ぶ**方向を検討する。ただし具体的なメニュー名・保存形式・フィールド名はまだ提案段階で、PWAと協議する。

1. **現状維持を初期状態とする。** アップデートや共通スキンの選択だけで、既存の本文テーマ、文字サイズ、利用者が選んだ共通ノーツや基地の操作設定を勝手に変えない。「現状維持」は現在すでに共通スキンから継承される部分も含む、現在の動作を保つ意味であり、すべてを固定色に戻すことではない。
2. 各領域に、現状維持・共通作品に連動・領域別に選択、などの選択肢が必要かを協議。書斎の「外枠」と既存の「本文テーマ」は分け、本文の見やすさや既存の選択を優先する。選択をプレビューするだけで適用・保存しない。
3. 適用前に対象と影響範囲を説明し、明示選択、設定の変更、元の状態への復元、失敗時の既存表示を用意する。前の値を自動で保持するか、別途リセットするか、複数領域を同時に適用する場合の扱いをPWA側で決める。書斎・基地の閉じる操作は常に見えるよう別途検証する。
4. レンダリングが未知のID・未対応の版・壊れた値・存在しない書体を受け取ったときは、利用者データや未対応設定を勝手に消さず、安全な既存表示に落とす方針を検討する。旧版への移行・保存・バックアップ・復元はPWAと合意しテストする。
5. データは許可済みIDや型・範囲を検証する設計を検討する。未検証のCSSやスクリプト、任意URL、端末上の本・メディアへの新規アクセスをスキンの配布物に持ち込まない。実装はCSP・同一生成元・ファイルのサイズ制限・バージョンなども別途設計する。
6. 強制色、文字拡大、reduced motion、フォーカス、キーボード・読み上げ、警告・状態の見え方を、各領域の実画面で確認。特に書斎の文章・編集・選択・検索ヒット、基地の再生・停止・字幕・動画・画中画・退出を保護する。操作を色だけに依存させない。
7. スキン選択のための通信・追跡や追加権限を前提にしない。書体・素材のサイズと利用条件、取得失敗・オフライン時の代替を示す。ユーザーが選んだ本・映像・書斎データに作品が触れる必要はない。

### ピクセル・コンソールでの領域別案

| 領域 | 表現の仮説 | 優先して守るもの | 状態 |
|---|---|---|---|
| 共通UI | 落ち着いた暗色と細い角形、少数の緑。 | スキン選択・警告・解除の読みやすさ。 | 静止見本のみ。 |
| 書斎 | 外枠に角形の秩序。本文は読みやすい面と書体、十分な余白。 | 現在の読書テーマ・フォント・拡大・編集・選択・しおり。 | 構想。PWAで作品別の外枠切替は未合意。 |
| 基地 | 背景の邪魔をしない操作面、控えめな緑と幾何学。 | 視認できる再生状態・字幕・動画・画中画・退出。映像自体の色を勝手に変えない。 | 構想。独立切替は未合意。 |

### 将来の検証

固定PWAを使い、共通・書斎・基地を個別に適用／拒否／解除／再起動／旧版・未知ID／バックアップ復元／オフライン／書体失敗／強制色／動画／狭い画面・200%拡大で試す。実際に読書・編集・再生・退出を行い、利用者や障害のある人を含むレビューを計画する。これらは**未実施**。Chromiumのみの確認は他ブラウザ・実機を保証しない。

## 5. 維持・修正しやすいカタログにするには

- 各作品に同じ見出し・状態・書体カード・出典・修正履歴を持たせ、対象領域を別々に追跡する。修正のたびに「なぜ、どこを、旧版との互換、何を再検証したか」を記録する。
- 一覧は導線と要約であり、根拠や制限を詳細ページで確認できるようにする。候補を採用済みに見せない。検索、候補なし、JavaScript無効時の一覧と、書体資料への到達を検査する。
- 正式なデータモデルの自動生成や既存ギャラリーを変える場合は、正本の `catalog/re-modern/records`、読みやすい詳細、公開パイプライン、ゲート・テスト・移行を一緒に設計する。現行の `typography` は1組のフィールドであり、複数書体・領域状態をそれだけで構造的に保証していない。今回の書式追加ではJSONの形式は変えず、詳細ページで分ける方針。
- ガイド変更に合わせ、`check-re-modern.mjs` は共通紹介書式のファイル存在を必須とし、欠けた場合をテストした。書式の利用状況や内容の正しさは検査できない。正規作品は現在0件なので既存作品のデータ移行はなく、Pages等の検査実行時にはこの書式ファイルが必要になる。
- [ガイドライン](../trk-re-modern-guidelines.md) と[個別紹介書式](../trk-re-modern-introduction-template.md)を参照。構造検査は真偽、権利、実装、検索の品質、人的レビューを保証しない。
