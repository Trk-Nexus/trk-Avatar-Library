## 相談したいことと受け入れ条件案

以下は Avatar 側の提案で、PWA 側の設計を一方的に決定するものではありません。

1. **設定棚と保存／適用**：既存の書体索引を拡張するか、別の受け口が必要か。保存だけ・適用・解除・削除の意味、利用者に見せる影響範囲と容量を分けられるか。作品の選択だけで書体を自動適用しない。
2. **適用先と既存設定**：対象はまず共通題字 `trk!` を候補とし、作品名一覧までの適用は未決。本文、その他の見出し、書斎、基地、再生・字幕、共通ノーツや既存パックを勝手に変更しない。利用者の書体・アクセシビリティ設定を優先し、後から変更された設定を解除時に古い値へ戻さない。
3. **依存と故障**：二書体案なら、各ファイルと個別の権利情報を確認し、両者が読み込まれて初めて適用する安全側の案。失敗・欠落・旧版・削除・容量不足では部分適用せず既存表示を維持し、状態と再試行を案内できるか。対象外の欠字は端末に依存することを示す。拡張なしでも作品を選べる方向で、意図した書体が未適用であることを分けて示す。
4. **権利と複数資源**：各書体の提供元・版・全文と著作権表示を別々に閲覧できるか。共通資源、同じファミリー名、更新、複数タブや競合、オフライン・再起動、未対応版の挙動を一緒に検討する。自動ダウンロード・利用者ファイル送信を前提としない。
5. **作品の範囲**：現行の作品色の受け口が題字以外にどこまでを扱えるか、将来の作品表現と保護範囲をどう分けるか。書斎・基地やスキン全体の適用を現時点で既成事実にしない。

検証の受け入れ条件として、PWA 側の実 UI で保存・適用・解除・削除・失敗、既存パック併用、ライセンス、再起動・他タブを、合意した版と環境で確認し、未対応を利用者に示すことを提案します。実機・異なるブラウザ・支援技術・各言語の読み手による評価は機械試験と別です。

## 共通題字色の相談用ファイル：再現と検査

入力の [`skin.json`](../../drafts/re-modern/pixel-console/skin.json) は現時点 SHA-256 `6039293db9c1a8f8974fce3e1f661ce68a206e9f0b485dea9827a2912a810419`。この値は入力の識別で、作者認証・承認や将来版のハッシュではありません。固定 PWA のクリーンな checkout、Node・依存関係・実行可能な Chromium を準備してください。取得や別ブランチへの変更は生成器が自動で行いません。

```sh
# /path/to/fixed-pwa は clean な 4f93a69f94ec3a3c14c6ea8d1cf9c064723b43e6
npm ci
TRK_PWA=/path/to/fixed-pwa node tools/build-re-modern-pwa-handoff.mjs
TRK_PWA=/path/to/fixed-pwa node tests/re-modern-pwa-handoff.test.mjs
```

生成先は Git 管理外の `dist/re-modern-pwa-handoff/pixel-console-consultation.stpack`。成功時には同パスを上書きするため、正式物や他人のデータを置かないこと。今回生成した SHA-256 は **`628bafef9c2b71e3246416d7770622fc3df0f4dca54a4960322e6848fea56ddd`**、36,813 B。ZIP のエントリは `pack.json`、`README.txt`、`LICENSE.txt` の3つで、書体やプログラムは含みません。入力・生成器・PWA のいずれかが変われば同一ハッシュを仮定しないでください。研究用 ZIP のハッシュは正式配布物を意味しません。

[試験](../../tests/re-modern-pwa-handoff.test.mjs)は固定版を一時コピーし、新規プロフィールの Chromium 133.0.6943.0、Service Worker・外部要求遮断で実施。2回生成した ZIP のバイト一致、PWA の manifest 検査と実際の UI 取込、未確認表示、開発用スイッチ OFF では色を適用しないこと、開発用 ON で既定背景に `#ecf6ee`／`#56d994` が指定されること、再読込と OFF 復帰を確認しました。この一条件で既存の skin・notes・題字 font の値は変わりませんでした。**色以外の作品全体、あらゆる設定、読み手、実機、支援技術、権利の保証ではありません。**

開発用スイッチは固定版の通常 UI に出ておらず、隔離した検証環境の開発者向け `window.TrkReModernDev.setUnverifiedPaint(true)` により有効になります。ON は保存され再読込後も残るため、終了時は表示される開発用バッジの OFF ボタン（または同 API に `false`）で止めて確認します。必ず専用の一時環境・新規プロフィールで、実ユーザーデータを使わずに行ってください。作者の承認や通常利用者向け操作を意味しません。
