## この裏面は何をするもの？

切替見本の表では、作品や選択肢の**見え方**を比べる。裏では、その見え方を形にした**概念・参考・選択の理由**を読めるようにする、という提案です。「裏面」は体験の呼び名であり、必ずカードを立体的に回転させることを意味しません。

読み手が気軽に作品へ入れる短い読み物と、後から出典や検討の経緯を追える記録をつなげます。開発途中のメモや未確定事項も残しますが、一般向けの文章とは表示上区別し、未確認を事実のように扱いません。

## 読み物の見本

### 小さな四角から、静かな画面へ

「ピクセル・コンソール」は、暗い舞台に限られた色と四角い形を置く、既存の `pixel-8bit` を出発点にした作品です。目指したのは、ある特定のゲーム機を忠実に再現することではありません。**ドットの秩序は残し、読むための文字は犠牲にしない。** そのバランスを、今の画面で考え直しています。

暗い面と角形は、画面に電子的なリズムを作るための選択です。いっぽうで、文章まで一律に粗い文字へ変えるのではなく、長く読む部分は落ち着いた書体にする方向を検討しました。走査線や強い発光を画面全体の主役にする案もありますが、この作品では、静かな面と少数のアクセントを優先しています。

### どの書体を選ぶ？

日本語の短い見出しには、**DotGothic16** を候補にしました。作者の説明によれば、16×16のゴシック体ビットマップをベースとした書体です。小さな四角の印象と日本語を同じ見出しに持ち込めるのではないか、と考えました。ただし、見え方や字種の十分さは実際の利用条件で確かめる必要があります。

もう一つ調べたのが、出発点のスキンに指定されていた **Press Start 2P** です。作者は1980年代のゲームに使われた文字から着想を得たと説明しています。こちらも魅力的ですが、今回の検討では日本語見出しとの一貫性を重視し、DotGothic16 を優先候補にしました。文字の出自については、それぞれの作者による資料にたどれるようにします。

**いま実際に使っているのは system 系の書体です。** 上記の二つは検討した候補で、この作品の制作データや研究用見本にはロードしていません。将来、書体を切り替えられるようにする場合も、表示できる文字、配布条件、読み込みに失敗したときの代替を先に確認します。

### 別の表情を選べるとしたら

今後の案として、たとえば「静かな面を中心にする」「装飾を少し強める」といった異なる表情を、同じ作品の考え方から比べることもできそうです。書体や文字の背後の面を別々に試し、どの場所に影響するかを見てから、自分で適用する。**これはこれからの提案で、現在選べる機能でも、過去に完成・承認された別構図でもありません。**

どの表情を選んでも、設定や解除が見つかり、書斎の本文設定や共通ノーツが勝手に変わらないことを大切にしたいと考えています。

## 体験としての作り方（提案・未実装）

1. **表：見本** — 選んだ案の見え方、対象領域、候補／実装済みの状態を示す。実際に動かない切替や適用ボタンは見せない。
2. **裏：読み物** — 「どんな概念？」「何を参考に？」「なぜその選択？」「他の案は？」「もっと調べる」を短く読み、詳しい記録へ移れる。
3. **詳しい制作記録** — 調査・判断・未確認・更新履歴と固定された資料への参照。完成した記事と開発中のメモを区別し、説明と一次資料をつなぐ。
4. **選択と設定** — 将来切替を実装する場合も、プレビューと適用は別。現在の設定を維持して開き、適用前に影響を示し、元に戻せるようにする。共通・書斎・基地は独立、本文・ノーツ・再生の既存設定を勝手に変えない。
5. **どの環境でも読める裏面** — 表裏の行き来は明示的なボタンやリンクで可能にし、キーボード、読み上げ、フォーカス、狭い画面、拡大に配慮する。回転演出を必須にせず、動きの軽減を尊重。JavaScript が使えないときも文章・出典へ到達できる構成を検討する。

こうした構成は既存の [個別作品紹介・カタログ書式](../trk-re-modern-introduction-template.md) と両立させる。構造化データや PWA の作品形式を拡張するなら、互換・移行・権利・公開経路を含めて別途合意する。
