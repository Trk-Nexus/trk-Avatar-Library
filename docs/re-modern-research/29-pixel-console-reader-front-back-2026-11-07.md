## 裏：四角い文字をたどる（読み物の草案）

### 四角を残して、画面を静かにする

出発点の `pixel-8bit` には、暗い色、四角いノーツと、ゲームの文字を思わせる `Press Start 2P` の名前があります。ただし、データに書体名があることと、見る人の端末でその書体が読み込まれることは別です。古い画面をそのまま再現するのではなく、**限られた要素が並ぶ秩序と電子的なリズム**を、読むための余白と並べられないか。その問いから「ピクセル・コンソール」を考えました。

背景は暗く、面の違いは控えめに。小さな緑の強調色が、操作や情報の位置を見つける手がかりになるように考えています。提案するノーツは暖色の四角と青いひし形です。形と色の両方で区別する意図はありますが、実際の見分けやすさはこれから確認します。作品を選ぶだけで共通ノーツは変わらず、別の「おすすめ」操作は共通設定を変更し、自動では元に戻りません。

### 日本語から、韓国語へ

[DotGothic16 の作者資料](https://github.com/fontworks-fonts/DotGothic16/blob/14517183ab2f75e8bccafc5a0bff6685d268c687/README-JP.md)は、16×16のゴシック体ビットマップを基にした書体と説明しています。短い日本語の見出しに、四角い画面の表情を重ねる手がかりです。

しかし今回の DotGothic16 日本語 subset には、作品の韓国語名 `픽셀 콘솔` に必要な4種類のハングルがありませんでした。そこで、DOS 用の韓国語ビットマップ書体を出発点に、作者が字形を追加した [NeoDunggeunmo](https://github.com/neodgm/neodgm/blob/cbe9a3c6b7067c62612570ee1261b39a31e5061b/README.en.md) を次の候補として調べました。二つを重ねることで今回の4言語名の個別文字を補えますが、それだけで全ての文章や、字形の自然さが保証されるわけではありません。

### 一つの書体なら、何が違う？

[Galmuri](https://github.com/quiple/galmuri/blob/71e1cacf1437a11220307120e63e30bc275312d4/README.md) の作者は、携帯ゲーム機の文字デザインから着想を得たと説明しています。今回の Galmuri11 固定ファイルには、作品の4言語名の各文字がありました。二書体をつなぐ案とは違う、ひとつの字形のまとまりを比較できます。

ただし、一つだから必ず小さいわけではありません。今回の WOFF2 は Galmuri11 が 505,400 B、Dot＋Neo の合計が 440,664 B。ライセンスやパックを含まないファイル単体の数字です。中国語の別の例 `你好` では、どちらの方向にも `你` が不足します。**文字があること、自然に読めること、配布できることは別々の問いです。**

### 英字のサブ基準：Press Start 2P

出発点のデータにも名前のある [Press Start 2P](https://github.com/codeman38/PressStart2P/blob/41826487a3d18e4e97f6e6ac166a376a79d1a7fa/README.md) は、作者によれば1980年代のアーケードゲームの字形に基づきます。短い英字を見たときの、ピクセル・レトロやドットらしさ。その感覚を比較するための**英字サブ基準候補**として残しました。

今回試した Latin subset には `trk!` や `Pixel Console` の文字がありますが、日本語作品名はありません。作者は他の字種も挙げており、今回のサブセットだけから書体全体の対応言語は判断できません。Press Start 2P を多言語の2案の代わりにする、3案をすべて同時に適用する、と決めたわけではありません。

### 文字を使うことと、文字を調べること

この作品案が今指定するのは system 系の書体です。上の3候補は研究見本で比較しましたが、作品に正式採用したり、PWA に拡張を実装したりしたわけではありません。書体を使う場合も、本文まで一律に変えるのではなく、どこに適用し、誰が選び、失敗したらどう戻るかを考えます。利用者自身の設定を大切にするためです。

[縁架ドット明朝24・横浜ドット・SolidLinker の寄り道](27-japanese-solidlinker-font-trail-2026-11-07.md)もあります。横浜ドットのフリー版には利用やサーバー送信・頒布に制限があり、候補として調べたことと作品に載せられることは別。調査の楽しさを残しながら、素材ごとの条件も確かめます。
