# ピクセル・コンソール：フォント入りの隔離研究見本

2026-11-07／[作業一覧 B3・C2](07-avatar-work-inventory-2026-11-07.md) の設計と、実際の書体ロードを試す初期見本。**正式な作品パック・PWA実装・公開・完成承認ではない。**

## 今回作ったもの

- [見本の HTML 原稿](pixel-console-font-study/index.html)は、制作案の暗い面・角形を使う独立ページ。自動的には PWA のスキン・書斎・基地・ノーツ・書体設定に触れない。
- 初期状態は system 系。利用者が選択すると、見本内の短い見出しだけ DotGothic16 を使用し、本文は system 系のまま。選択はその場限りで保存しない。ラジオ操作は JavaScript 不要。現在の構図や文章は研究用であり、PWA 画面の再現ではない。
- ローカルに用意するのは既存 `font-packs/dotgothic.stpack` 内の日本語 WOFF2（396,312 B）と OFL 全文。準備ツールは入力 pack・WOFF2・ライセンスの SHA-256 を照合し、不一致なら停止する。ブラウザが書体を使う時も同じ見本のオリジンから読み込み、外部サイトの書体を自動取得しない。外部資料へのリンクは明示的に開く場合のみ遷移する。
- 書体を提供する根拠は [B2 の出典・配布差分](11-dotgothic-distribution-inventory-2026-11-07.md) に記録。研究用コピーに OFL 全文・著作権表示と `FONT-SOURCE.txt` を添えるが、これをもって権利の最終確認や正式な再配布方針の承認とはしない。

## 準備と起動

```sh
# clean な PWA checkout の js/zip-io.js を使って既存 pack を読む。ネットワーク取得はしない。
node tools/prepare-re-modern-font-study.mjs --trk=/path/to/trk-PWA
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist/re-modern-font-study
# 自分の端末で http://127.0.0.1:4175/ を開く。Ctrl-C で停止。
```

`dist/re-modern-font-study` は生成用・Git 管理外。別の出力先は `--out=/path/to/output`（指定した出力先の見本ファイルは上書き）で指定可能。コマンドは pack 自体を変更しない。研究中に使った PWA ZIP 実装は main `4f93a69f94ec3a3c14c6ea8d1cf9c064723b43e6`。見本を別環境に置く場合は OFL と出典を欠落させず、配布・公開の可否を別途確認する。

## 確認したことと限界

[自動試験](../../tests/re-modern-font-study.test.mjs)を Linux sandbox の headless Chromium 133.0.6943.0 で実施。

- JS無効・Service Worker無効の隔離プロフィールで、初期 system 系、キーボードによる書体選択、WOFF2 の `FontFace` が `loaded`、本文の font-family が変わらないことを確認。選択時まで WOFF2 を要求せず、外部要求は遮断。再読込すると初期 system に戻る。
- 1280／390／320 CSS px とルート文字サイズ100%／200%で横方向の document overflow がないことを確認。forced colors と reduced motion のエミュレーション中に見出しが存在・表示されることを確認。これは実際のブラウザ拡大、色の見やすさ・操作性・読み上げの適合を証明しない。
- ローカル WOFF2 読込を意図的に遮断するとフォントは未読込となり、見出し要素は表示された。代替フォントの種類・すべての字形の可読性を確認したものではなく、現在は読み込み失敗を個別通知する UI もない。
- この WOFF2 の cmap で見出し文字 `ピクセル・コンソール PIXEL CONSOLE 0123` の重複を除いた22文字は全て収録。試例 `你好` では `你`、`한글` では `한` と `글` が未収録。字種の一例であって言語全体のサポートや字形の品質の証明ではない。日本語サブセットのため、欠ける字は端末の代替書体に依存する。
- この見本にはフォント切替以外の「適用」や未実装のボタンは置いていない。画面の比較や人の見やすさ、実機、他ブラウザ、支援技術、ネイティブのズームとネットワーク失敗時の丁寧な状態表示は未検証。

## 表・裏と別案の設計（B3）

1. **表＝見本**：現在選んだ対象・書体・見え方を示す。初期状態は利用者の現状を維持。今回の見本は書体を比較できるが、作品への適用機能はない。
2. **裏＝読み物**：[読者向け草案](09-pixel-console-reader-draft.md)に、着想、残した点、書体候補と選択理由、未実装の別案、一次資料へのリンクを置く。記録は[別の制作メモ](10-pixel-console-development-notes.md)に残す。
3. **切り替え**：表と読み物は回転を必須にせず、明示的なリンク／ボタンで開ける構成を検討。キーボード、読み上げ、フォーカス、拡大、狭幅、動き軽減、JS無効時を個別に試す。今回の HTML はまだ表裏切替を実装していない。
4. **将来の適用**：プレビューと適用・保存を分離し、共通／書斎／基地ごとに影響、現在の設定、導入容量、失敗・解除・復元を説明。本文・共通ノーツ・字幕や再生を勝手に変更しない。PWA の既存データ形式にこの見本を読み込ませる設計ではない。

## 基本書体と別案の方針（2026-11-07 追記）

依頼者の方針として、概念に合い配布条件を満たす書体を原則一つ以上、導入後の基本表示として使えるようにし、同梱できない書体は許諾を確認した見本画像や利用者自身の入手による任意案も検討する。[条件と実現上の課題](14-font-distribution-and-user-choice-2026-11-07.md)を別に記録した。見本画像の作成・公開にも利用条件があり、権利未確認の画像は作らない・掲載しない。

この見本は**初期状態が system 系の隔離比較**で、作品を導入した時に基本書体を表示する経路とは異なる。WOFF2 の cmap と現行4言語の作品名を確認したところ、日本語・英語・中国語の作品名の個々の文字は収録、韓国語の4文字は未収録。対象言語全体・字形の品質は別途確認が必要。PWA には現時点でこの書体を作品ファイルから供給する受け口がなく、同梱して使える完成版とは呼べない。

## フォント込みの完成案まで残るもの

- 利用者が見本の方向性と、実際に使用する見出し・対象領域を確認する。DotGothic16 に固定するか、system のままにするか、他の選択肢を含めるかは未決。
- 全ての文字・言語の扱い、欠字時・ロード失敗時の明示、字間・拡大・視認性、実機／他ブラウザ／支援技術を検証する。書体そのものの権利・配布、OFL 表示、容量・更新を独立にレビュー。
- PWA の既存「電子ゲーム」組やスキン付き既存パックは、個々に本文・見た目・ノーツへ影響し得る。見出し専用供給、ユーザー選択・他の書体設定との優先順位、失敗・解除、古い PWA における互換を固定版で確認し、実行方法を PWA 側と協議する。
- 導入／適用／プレビュー／解除を利用者が選び、勝手な外部通信や設定の上書きがないことを作品ごとに確認する。正式登録・公開・配布は別判断。

フォント入りの**見本**には到達したが、PWA に載せられる完成案とはまだ呼ばない。
