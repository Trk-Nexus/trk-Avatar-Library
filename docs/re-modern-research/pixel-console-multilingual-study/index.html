短い文字列で比べる

初めはこの端末の system 系です。「二書体の候補」を選ぶと、下の見本文字列だけ DotGothic16、NeoDunggeunmo、端末の system 系の順に使います。説明文は変えません。候補の実際の適用対象は未決です。

比較操作はこのページ内だけで、作品への適用や導入ではありません。書体が欠ける・読込に失敗する場合は代替され、表示が端末により異なります。この見本は失敗の通知や、両書体が揃うまで適用を待つ機能を持ちません。

人に確かめてもらいたいこと

  • 文字を見分けやすいか、字間や大きさは適切か。
  • 中国語や韓国語の字形・組版が、その言語や地域の読み手に自然か。
  • 端末の system 系と比べて、作品の意図に合うか。読みにくければどこが気になるか。

実機、他ブラウザ、実際のズーム、支援技術、各言語の読み手による確認は未完了です。文字の存在や自動試験だけでは読みやすさを保証できません。
