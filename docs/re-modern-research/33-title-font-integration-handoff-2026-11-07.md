# 題字と書体の接続：PWA向け一括提案・試作

2026-11-07／Avatar側。PWA [`1fd6a89ebc4be4eba100a53f554fc2f6e97c752e`](https://github.com/Trk-Nexus/trk-PWA/tree/1fd6a89ebc4be4eba100a53f554fc2f6e97c752e) を基準にした提案と実行可能な**隔離モデル**です。PWA本体に組み込んだ実装、フォント配布、作品の正式登録や公開ではありません。[統合レビューへの検討32](32-integration-review-title-license-2026-11-07.md)の後、依頼者は「題字を主役、書体とライセンスは詳細」「明示された全体設定を優先、作品連携は別途オン」を了承しました。PWA側の設計・実装・検証をお願いする材料であり、未合意の形式を一方的に決定しません。

## 1. PWA側が最初に知ること

- ピクセル・コンソールは作品**案**を承認済みですが、正式登録・公開・フォント最終採用は別です。制作データの現在の題字と本文は `system-ui, sans-serif`。端末の実書体は異なります。
- DotGothic16＋NeoDunggeunmo と Galmuri11 は多言語の**主な比較基準**、Press Start 2P はピクセルレトロ／ドットらしさを比較する**英字サブ基準**。これらを作品に採用・推奨する決定でも、同時に導入させる指示でもありません。
- 全体の題字設定は共通題字と**全作品カード**が対象。今回提案する作品連携は明示的にオンにした場合の**共通題字と当該作品カードのみ**。PWAの現行 `fontForWork` は作品指定を先に返しますが、**画面適用には未接続**であり、この提案の優先順位にするにはPWA側での変更・試験が必要です。
- 現行PWA `checkManifest` は未知の `titleFont` を捨て、`heading.font` の `dotneo` は拒否します。**本資料の JSON は現行 `.stpack` の形式でも、PWAが読める仕様でもありません。** 作品パックに試しに混ぜて「連携済み」としないでください。

## 2. 表示・情報の分担

[題字中心の見本](title-font-integration/preview.html)は説明用の静的ページで、作品名・概念が先、書体名と各著作権・ライセンスへのリンクは詳細です。JSなしで読めます。**書体のインストール・適用やオフラインの全文表示を実装したものではありません。** その見本は PWAの固定版 `fonts/licenses/` の各ファイルへの外部リンクであり、リンク先閲覧には通信が必要です。

製品では、次の情報を利用者に分かる形で提供することを提案します。

| 場所 | 表示内容 |
|---|---|
| 表 | 題字／作品名、短い概念、作品と表示機能の状態、「書体とライセンス」への導線。候補一覧を題字より目立たせない。 |
| 書体とライセンス | 実際の指定／現在の選択／研究候補を分け、**正式書体名、版・供給元、対象箇所、各著作権表示・各ライセンス全文、未導入とfallback**を示す。system系の解決先は推測しない。 |
| 機械用 | 候補ID、各ファイルID・hash・byteと、各ファイルのライセンス情報を対応付ける。表示名やライセンス本文からIDを推測しない。 |

OFLなどの作者の原文・著作権表示は**それぞれそのまま**扱い、作品側の書体名や説明は別のラベル／NOTICEで添える。作品のライセンスと書体のライセンスを混同せず、画像・配布・利用条件は対象版ごとに再確認する。著作権・権利の最終判断を代行するものではありません。

## 3. 接続のための識別・受け渡し案

添付の [`catalog.proposal.json`](title-font-integration/catalog.proposal.json) は、PWA候補IDを既存のまま参照し、組の構成を分けた**研究用対応表**です。固定版の4ファイル・4ライセンスのsha256・byteを記録。`selectedCandidate: null` は**どの候補も作品の正式書体として選定していない**ことを示します。データはネットワーク取得を行わず、同梱するフォント本体もありません。作者の取得先・固定版の詳細は[回答31](31-pwa-trk315-consolidated-response-2026-11-07.md)。

| 組のID（PWA） | 個別ファイルID（PWA） | 役割 |
|---|---|---|
| `dotneo` | `dotgothic16` → `neodunggeunmo` | 多言語比較、2ファイル・2ライセンス。CSSの順は文字単位のfallbackで、言語ごとに必ず分かれるわけではない。 |
| `galmuri` | `galmuri11` | 多言語比較。PWA全体設定での推奨表示と作品の正式採用は別。 |
| `press` | `pressstart2p` | 英字サブ比較。今回のLatin subsetは日中韓用ではない。 |

作品ID／候補ID／個別ファイルID／表示名／実バイト／ライセンスは**異なるもの**。[`pixel-console-font-contract.json`](pixel-console-font-contract.json) の旧研究素材IDは別の名前空間で、`heading.font: "dotgothic"` を `dotneo` と同一視しません。具体的なJSON形・正本の管理者・版・更新・命名はPWA側と最終合意が必要です。

**対応方式の推奨**：PWAが検証した候補一覧を持ち、作品はその**許可された候補IDだけ**を参照する。候補IDは提案や参照を示すものであり、利用者の選択や導入状態ではない。今回の候補一覧を作品へ埋め込むことや、任意のフォント・URL・CSS・JSの実行は求めません。認証されない作品の内容をそのまま権限ある適用指示として扱わず、既存の登録／未確認の規則を維持します。

### 後方互換と更新

- 現行v1の未知項目が黙って落ちるため、受け口なしで `titleFont` を付け足す方式は避ける。将来の作品形式の版引き上げ、またはPWA側で明示的な対応判定ができる**別の参照情報**を候補とする。どちらも未実装。旧PWAが作品を読めても書体連携は機能しないことを明示し、無理な自動フォールバックや設定変更をしない。
- 作品ごとの「どの候補を使うか」と「連携オン／オフ」は利用者設定として分け、初期値はオフ。旧状態が空の場合もオフのまま移行。既存 `heading.font` は未合意で削除・変換しない。
- 既存の候補IDの構成・byte／hashを更新すると旧保存値の解釈に影響する。将来のIDの不変条件、版／別ID、旧ファイルの保持・更新・移行、利用者への案内をPWAと決める。新・旧ファイルや別作品の共有を参照カウント等で管理し、他の利用者選択が使うファイルを誤削除しない。

## 4. 優先順位と、オン／オフ

**利用者が明示した全体設定 ＞ 別途オンにした対象作品の連携 ＞ 既存表示**。作品を選ぶだけでは拡張をオンにしません。

| 全体設定 | 対象作品の連携 | 期待する表示 |
|---|---|---|
| オフ | オフ／未設定 | 現在の表示を維持。旧ユーザーもこれを初期値とする。 |
| Galmuri を明示 | Dot＋Neo を明示オン | 全体Galmuri。作品の設定値を消さない。全カードへの影響を全体設定画面に明記。 |
| オフ | 対象作品でDot＋Neoを明示オン | 共通題字と**その作品のカードだけ**に適用。他の作品・本文・書斎・基地・ノーツを変えない。 |
| オフ | 別作品を選択／現状維持 | ピクセル・コンソール由来の指定を外し、現在の既存表示を使う。保存された書体ファイルは削除しない。 |
| 選択中の全体候補が未導入／不正／ロード不能 | 作品連携オン | 作品へ黙って乗り換えない。元の安全な表示に戻し、全体候補の状態と再試行を示す。 |

「全体の題字書体を使わない」は**全体設定のみオフ**という意味を表示し、作品連携は明示操作なしでは有効化しません。「どの拡張も使わない」操作は別の明確な操作として設ける案。ラベル・アクセシビリティ・設定の具体的な配置はPWA側で選べます。作品連携の解除とフォントファイルの削除は別操作で、既存の設定や選択の値を勝手に消さないでください。

## 5. 準備・確定・復帰の契約

「選択候補を受け取った」だけでは適用済みとしない。候補ごとの**全ファイルの版・hashと読み込み**を確認し、一つでも失敗すれば部分適用しない。フォント情報の全文提示・ネットワークの扱い・規約確認も別々に行う。

1. **準備**：候補・対象・利用者設定・登録状態・保存状態の最新値を確認。必要な全ファイルを検証し、各 FontFace を仮ロード。まだ既存の選択・表示は変更しない。未導入なら案内し、自動取得しない。
2. **確定**：準備後に対象作品・優先設定・データ版が変わっていないことを再確認し、新選択と表示を整合させる。localStorage、IndexedDB、DOMを一つのトランザクションとしては扱えないため、ホスト側で実施順序・所有権・補償／整合再読取を設計する。
3. **失敗**：準備・確定が失敗し旧状態が保たれたことを確認できるなら、旧表示・旧選択を維持し、失敗を返す。保存結果が不明・外部変更があった場合は当該機能が所有する表示だけを外し、不明として再読取。古いスナップショットで利用者設定を上書きしない。
4. **取消・競合**：作品変更、明示設定変更、解除、更新、他タブ、再起動で古い準備結果を使わない。遅れて完了した FontFace 等はホスト側が解放し、別の作品や設定の資源を消さない。部分準備の失敗や重複通知でも未確定資源のみを冪等に片付け、既に確定した資源は解放しない。世代番号だけでは既に開始した別タブの書込みを取消・直列化できない。ロック・コミット順の確認・通知と復旧を実装・試験する。
5. **利用者への状態**：保存済み／未導入、読み込み中、適用中、適用なし、失敗・再試行を区別。前回の PWA `1fd6a89` では、欠落時は選択を保つ一方、hash照合後の FontFace失敗注入では先に新選択が保存され `ok: true` になりました（[研究32](32-integration-review-title-license-2026-11-07.md)の模擬試験）。ロード・確定失敗の結果までUIに反映することを推奨します。

## 6. 添付モデルと受け入れ例

[`model.mjs`](title-font-integration/model.mjs) は**純粋な研究モデル**です。対象・優先順位、ready/unavailable、段階的な選択と遅れて届いた結果の扱いを返します。`ready` はホストが実際にhash照合・全FontFace読込を完了したとの**仮定**であり、モデル自身は一切の入出力・検証・保存・DOM操作を行いません。`committed`／`rolled-back` はホストが保証した結果を表すイベントであり、複数ストアに原子性があるという意味ではありません。古いcommitが実際に走った可能性があれば再整合が必要です。実装にそのままコピーして安全とみなさないでください。

```sh
# Avatar側、Node 22。依存なしの純粋モデル検査。
node --test tests/re-modern-title-integration.test.mjs
# PWA固定版コピーがあれば、候補ID・4ファイルとライセンス全文のhashも照合。
TRK_PWA_REVIEW=/path/to/pwa-1fd6a89 node --test tests/re-modern-title-integration.test.mjs
# 現行PWAの未知項目・優先・障害特性（模擬）
TRK_PWA_REVIEW=/path/to/pwa-1fd6a89 node --test tests/re-modern-integration-review.test.mjs
# 別途4つの固定フォントを取得した場合、バイト数・SHA-256を実ファイルで照合。
TRK_TITLE_FONT_DIR=/path/to/font-files node --test tests/re-modern-title-integration.test.mjs
# 静的見本の独立ブラウザ試験（npm ci と Chromium 環境が必要）
node tests/re-modern-title-integration-browser.test.mjs
```

PWA側の受け入れ試験としては、少なくとも以下を用意してください。

- 旧PWA・候補不明・未登録作品・色のみの現行pack・新形式／別参照の不一致。無断適用せず、旧設定と題字の表示が壊れない。
- 上表の全体／作品の組合せ、全体オフと作品オフ、作品変更、他カード・本文・ノーツの不変、通常状態と既存書体設定への復帰。
- 未導入、片方だけ、壊れた・旧版・hash違い、各 FontFace の失敗、選択の保存失敗、確定結果不明、解除・再起動・削除、共有ファイルと複数作品、逆順完了、複数タブ。
- 4つの著作権表示と各全文、導入しない表示、失敗後再試行、オフライン／モバイル staging、旧版→新版→オフライン起動、狭幅・拡大・フォーカス・読み上げ・言語話者の確認。
- 自動検査・実ブラウザ・実機・人の字形と権利確認を分けて記録。PWA側の対応をテストと文書で示してから、正式登録・配布・公開を個別に判断する。

## 7. 今回の範囲と未完

Avatar側では、表裏の文案、4ファイルの対応表、意思決定と失敗を表す模擬モデル・テスト、JSなしの見本を用意しました。固定PWAの候補・4ライセンスと、別途取得した4フォント実ファイルのbyte／hashを照合しました。見本は隔離Chromium 133でJS無効・キーボード・320／390／1280幅・100／200%・forced colorsを検査しました。これらはPWA本体の連携試験ではありません。PWA側の実画面やストレージへの接続、他ブラウザ・実機・支援技術・言語話者・権利の最終判断は未了です。相談用の題字色 `.stpack` は従来どおり作品全体ではなく、正式登録0件は維持します。PWA側の採用形式・候補IDの管理・追加機能の実装とレビューはPWA側で判断してください。
