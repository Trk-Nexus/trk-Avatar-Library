## 1. 今の方向性

> 懐かしさを再現するのではなく、ドットの秩序と、いま読むための余白を同居させる。

**美学と機能の併用案**とする。暗い電子画面の静けさを基調に、角形・限られた色でリズムを作る。画面全体の発光、走査線、常時アニメーションはアイデンティティの必須条件にしない。本文をドット風に粗くすることよりも、読むための文字・操作・設定を優先する。

### 設計判断と境界

| 項目 | 進める方向 | まだ約束できないこと |
|---|---|---|
| リメイク | `pixel-8bit` の暗い舞台と限定色を出発点に、新しい別 ID とする。元作品は変更しない。 | 特定ハードウェアやゲームの復刻ではない。現時点で独自性の人手比較は未完。 |
| 表情 | 見本では暗い地、角形の区切りと小さいドット状の装飾を使う。要素は静止。 | 見本の配置やドット装飾がそのまま PWA のスキンだけで実現するとは言えない。 |
| 色 | 前回の候補色を設計ベースにする。アクセントは緑、ノーツの提案は暖色／青。色だけを唯一の意味にしない。 | PWAの実合成、動画、フォーカス、ボーダーなどの見え方は未検証。色を確定したのではない。 |
| 書体 | DotGothic16 Regular 400 を短い見出しの候補にし、本文は system 系を優先。 | まだ同梱・適用しない。PWAで見出しだけに適用できる方法、出典と代替、字種を解決する必要がある。見本は標準書体。 |
| ノーツ | 四角／ひし形は**任意のおすすめ**として検討する。利用者の共通設定をスキン選択だけで変えない。 | 見本どおりに自動適用されない。小ささ・モード・画像・視認性を含め実ゲームでの確認が必要。 |
| 演出 | スキン専用の点滅・走査線・ゆがみを前提にしない。 | 共通のゲーム演出や映像を止めた、または安全性を評価したという意味ではない。 |
| 透過 | 文字の背後を落ち着かせる。背景に依存した文字・操作を避ける。 | 現PWA変換のパネルは96%不透明。完全不透明を約束せず、実際の重なりを検証する。 |
| 通信・権限 | 見本は単一 HTML の静的資料で、外部アセット、外部通信、追加権限、保存を要求しない。作品も追加の追跡や権限を前提にしない。 | ローカルHTTP提供は文書の取得として通信する。PWA本体の通信や保存は別であり、この試験はオフライン対応を保証しない。 |

### あえて採用しない／保留する理由

- **原色の赤と緑をそのまま二種類の唯一の違いにする案**：元作との連続性は強いが、色情報だけへの依存を避けたい。色の変更も万人の識別を保証しないため、形・案内・人手確認が必要。
- **ドット書体をすべての本文に広げる案**：統一感は強いが、小さな文字や長文、多言語のフォールバックの検証が難しい。見出し限定を目標とするが、現在の PWA で実現可能と決めつけない。
- **走査線や発光を標準にする案**：レトロ感は強いが、既存「ドットの電子音」との差が薄く、背景や文字との競合が増える。静かな面を優先する。
- **スキン選択時にノーツを自動上書きする案**：見本に近づけやすいが、利用者の共通設定を勝手に変える。既存の明示的な「スキンのおすすめ」を候補とするが、下記の復元課題を解決するまで安全な解除と呼ばない。

## 2. PWAの既存機能：前回の調査への補足

固定PWA `f7b1272547f712d9a7d7a198404148457e936008` の [custom.js](https://github.com/Trk-Nexus/trk-PWA/blob/f7b1272547f712d9a7d7a198404148457e936008/js/custom.js) と [index.html](https://github.com/Trk-Nexus/trk-PWA/blob/f7b1272547f712d9a7d7a198404148457e936008/index.html) を再調査し、設定内に **「スキンのおすすめ」** ボタンが既にあることを確認した。前回はこのボタンを見落としていた。

- スキンの `game.don`、`game.ka`、`shapes` は、そのボタンを押したときの**おすすめ**として使われる。通常のゲーム描画は利用者共通の `settings.notes` を参照する。
- 明示的におすすめボタンを押すと、現在の共通ノーツ設定が置き換わり、保存される。スキン切替で元のノーツには自動的に戻らない。
- PWAのパック機構には別の退避・復元処理もあるが、上記ボタン自体の自動 Undo を意味しない。パック版と内蔵スキン版は混同しない。
- 現時点の推奨案は、スキン選択時には既存のノーツを尊重し、希望者だけに「スキンのおすすめ」を案内すること。その前に元の色・形を控え、設定欄で手動で戻せることを示す必要がある。ただし操作・復元を利用者テストしたわけではなく、誰にでも十分な解除経路とはまだ判断しない。自動Undoや前の値の提示の要否はPWA側と別途検討する。

### 実際に試した限定テスト

[再現テスト](../../tests/re-modern-pixel-pwa-browser.test.mjs) は、固定PWAの**クリーンな一時コピー**に仮データをインポートし、既存本体・本番データを書き換えず実行した。`core.applySkin` を直接呼び、実際の「スキンのおすすめ」ボタンをクリック。新規プロファイルの初期ノーツを対象とした。

| 操作 | 結果 |
|---|---|
| 仮スキンを選ぶ | 共通ノーツは変化しない |
| 「スキンのおすすめ」を押す | ドン `#ff8069`／四角、カッ `#69b8ff`／ひし形になる |
| ページを再読み込み | 上記の共通設定が残る |
| 別の `shadow` スキンに切り替える | 上記の共通設定がそのまま残る |
| 設定欄に控えておいた初期色・形を入力 | 初期値に戻った。色入力は合成イベント、形の選択は自動操作 |

2026-11-06、Linux sandbox、Playwright Core 1.50.1、Chromium 133.0.6943.0（`@sparticuz/chromium` 133.0.0、headless）。サービスワーカーを無効にし、テストサーバー外の要求を遮断。色はテストコードから値を設定して input イベントを発火し、形は select を自動操作したもので、ネイティブの色選択器や人による手動復元の検証ではない。画面の一覧から仮スキンを選ぶ操作、他モード、実機、画像ノーツ、配布パック、旧PWA、オフラインや支援技術は検査していない。ボタンを押せたことは、見分けやすさやアクセシビリティの証明ではない。

```sh
TRK_PWA=/path/to/clean-fixed-pwa node tests/re-modern-pixel-pwa-browser.test.mjs
```

指定されたクリーンな PWA checkout が必要。目録は研究時の SHA またはその記録された基準版を使い、基準版の場合は[履歴差分](pixel-console-catalog.patch)を一時コピーだけに適用して SHA を確認する（[詳細](01-pixel-console.md#4-一時的な-pwa-色実験)）。Chromium が利用できることも必要で、環境によっては共有ライブラリの設定が要る。PWA checkout や正本の目録は直接書き換えない。

## 3. 実装経路の比較と保留点

**2026-11-06 補足・前回の見落とし**：固定PWAには、見出し等と説明文に別の書体を指定する既存の「書体の組み合わせ」があり、`電子ゲーム` は DotGothic を題字用に指定する。ただし組の選択は書体をインストールせず、全見出し・本文・ゲームに一律適用されるものでもない。パック使用時の設定・供給と解除の検証も必要。詳細と限定検証は [正式作品に向けた制作案](../../drafts/re-modern/pixel-console/README.md#補足既存の書体の組み合わせ) を参照。下表はパックだけでは解決しない点を示し、既存の組み合わせ機能がないという意味ではない。

| 経路 | 良い点 | 欠点・条件 | 現時点の判断 |
|---|---|---|---|
| 通常スキン＋既存のおすすめボタン | スキンの選択では共通ノーツを変えず、利用者が明示的に提案を選べる。PWAの既存入口を使える。 | ボタンの後は共通設定が持続し、切替で自動復元しない。書体を供給する仕組みは別。 | **優先して検討**。元の設定の記録・復元方法と画面の案内が受容可能か要確認。 |
| 書体だけのパック | パック経由で書体を読み込める既存機構がある。 | 現行PWAではロード書体を `--font` の先頭へ置くため、本文にも及び得る。見出し限定を満たすと限らない。 | そのままでは今回の目標を満たすと断定できず、代替案。 |
| スキン＋書体・ノーツ入りパック | 書体、見た目とノーツをひとまとめにできる。 | パックを使う操作はスキン・ノーツの共通設定も変え得る。既存の退避・復元条件を検証し、事前説明が必要。本文への書体適用も要確認。 | 本案での採用は保留。 |
| PWAに見出し専用の読み込みを追加 | 本文と見出しを分離する目標に近づけられる可能性。 | 新規のPWA仕様・配布・失敗時・更新・解除・容量・オフライン・セキュリティの合意と実装検証が必要。 | Avatar側だけで決めない。 |

どの経路でも、ユーザーが指定した書体やノーツを尊重し、容量や適用範囲を説明する。現PWAで新カテゴリが一覧・検索・巻としてどう見えるかは、この試験では評価していない。

## 4. 透明度の予備検算

固定PWAでパネルは `rgba(23,34,41,0.96)` に変換される。sRGB成分を使って `前景×0.96 + 背景×0.04` で混合した**単純な仮定**の下、合成後の背景と本文／補足の比を相対輝度で計算した。実際のブラウザでこの背後に置かれるもの、複数レイヤー、映像、ブラー、アンチエイリアスを測ったものではない。

| 単色の仮の背後 | 本文 `#ecf6ee` | 補足 `#b8c9bd` |
|---|---:|---:|
| 黒 `#000000` | 14.858:1 | 9.492:1 |
| 候補背景 `#10151a` | 14.717:1 | 9.402:1 |
| 白 `#ffffff` | 13.084:1 | 8.359:1 |

画面上の実際の合成と状態・枠・フォーカスの検査は依然として必要。数字をもって PWA 画面の WCAG 適合としない。

## 5. 見本の範囲と確認記録

見本は単一 HTML と CSS で構成。ラベル、図形、仮の画面、ドット状の装飾はこの検討用に作った静止表現で、第三者のロゴやゲーム画面を模倣する意図はない。候補色を示すための**概念図**であって PWA のレイアウト・実装の再現ではない。スキンを適用するボタンや、動かない偽の操作を置いていない。フォントは端末の `system-ui` 等で、DotGothic16のバイナリは見本に含めず、外部からも取得しない。

[見本テスト](../../tests/re-modern-pixel-preview.test.mjs) を 2026-11-06 に Linux sandbox、Playwright Core 1.50.1／headless Chromium 133.0.6943.0 で実施。1280・390・320 CSS px、ルート文字サイズ 100%／200% で横方向の文書はみ出しがないこと、ページエラーなし、追加ネットワーク要求なしを機械的に確認。forced colors／reduced motion の**エミュレーションを有効にして見出しが存在・表示される**ことを確認した。これは各状態の視覚的な適合、実機やブラウザズーム、すべての要素のコントラスト、キーボード、読み上げ、色覚多様性への適合の証明ではない。

スクリーンショットで日本語を表示するため、テスト環境には一時的に Google Fonts の Noto Sans JP（リポジトリ commit `24ddc1f324cac5d9f5aedca126d298f56e3f1640` の `ofl/notosansjp/NotoSansJP[wght].ttf`）をOS側のフォント設定に追加した。見本にフォントは同梱されず、利用者の環境では異なるフォントになり得る。Chromiumの起動には一時的にビルドしたNSS/NSPRライブラリを使用した。Firefox、Safari、実機、人による確認は未実施。

```sh
node tests/re-modern-pixel-preview.test.mjs
```

実行にはこのリポジトリの開発依存と、起動可能な Chromium が必要。環境によって共有ライブラリの設定が必要。

## 6. 公開・登録へ進むための残課題

1. **方向性の人手レビュー**：見本の色・暗さ・装飾密度・固有性を確認。仮の見本と元作品、既存「ドットの電子音」はまだ実画面で比較していない。ユーザーの今回の肯定的反応は詳細デザインや公開の承認とは扱わない。
2. **書体と権利**：DotGothic16 の既存出典リンクの404を、元資料・パック・目録・リリースで整合させる。配布する実ファイル、作者・版、OFL、表示・改変・再配布条件とハッシュを確認。前回の日本語 subset は全言語をカバーしない。見出し専用のロード方法・失敗時の system 系代替・字種・拡大・混植をPWA側と検討する。許諾未確認の新規同梱はしない。
3. **ノーツと解除**：既存の「スキンのおすすめ」の効果と持続を説明し、元の値の控え方・変更・手動復元を実際に試す。さらに画像ノーツ、レイアウト、速度、色覚多様性、当事者のレビューを計画する。必要ならPWA側に追加の解除・説明の提案を行う。
4. **画面・安全性**：PWAの実画面で合成色、通常／選択／hover／フォーカス／無効の状態、境界、警告と解除を検証。動画、狭い画面、200%拡大、強制色、reduced motion、キーボード、読み上げ、タッチ、IME、オフライン・失敗時を確認。美観が安全操作を覆わないこと。
5. **互換・配布**：新カテゴリの棚・検索・巻、PWA固定版・旧版、パックの切替・復元、容量、通信を調査。未合意のPWA仕様は勝手に追加しない。記録・ページ・一覧・台帳を整え、別の人が証拠をレビューした後に公開判断する。

`npm run check:re-modern` は台帳・記録の構造検査であり、上記のレビューや実環境の安全性・素材の権利を保証しない。現時点では作品を台帳や正本に追加していない。
