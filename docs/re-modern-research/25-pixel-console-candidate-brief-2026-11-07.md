## 現在の基準案：何を、いつ変えるか

- 共通領域に作品を選び、利用者が書体使用を明示的に選んだ場合の **固定 PWA の `.brand h1`＝`trk!`** を適用候補とする。作品名の4言語は比較対象であり、作品一覧・その他の UI を勝手に変更する仕様ではない。
- 二書体は Dot → Neo → 利用者の既存書体スタック → system 系の順を候補にする。既存スタックの取得・優先順位の実装は未決。利用者の明示的な設定・読みやすさの設定を優先し、作品導入だけで自動変更しない。
- 本文・説明、他の見出し、書斎、基地、再生・字幕、共通ノーツ、他のスキン／パックをこの拡張からは変更しない。利用者による既存の選択はそのまま。共通ノーツの「スキンのおすすめ」は別操作で設定が残るため、自動復元されると説明しない。
- **導入／保存だけでは適用しない、適用／解除／削除は別の意味**という設計案。二書体とライセンスが検証され、両書体がロードされた後、適用先への反映も成功してはじめて適用済みとする。欠落・不一致・ロード失敗・利用者優先時は既存表示を維持し、理由や再試行を案内する案。[純粋モデル](21-font-state-and-recovery-study-2026-11-07.md)。実ストレージ・複数タブの保証ではない。

## 判断・作業の残り

1. **候補の評価**：二書体と Galmuri の見本を、人が字形・作品の印象・読みやすさで比較。中国語の地域や韓国語の自然さ、本文との組み合わせを各読み手に確認。現時点で「best」は未決。
2. **配布と権利**：各実ファイルの OFL・著作権・出自・予約名と、見本画像の作成／公開、過去の DotGothic 配布物の訂正・案内を独立にレビュー。法的承認を自動テストから推測しない。
3. **体験を完成させる**：導入、保存、適用、利用者設定優先、欠落・失敗時の説明、解除、更新・再起動・他タブの資源を実装環境で確認する。研究モデル・見本をそのまま製品としない。
4. **画面と操作の確認**：PWA の実画面・動画背景・色と境界・ノーツ・キーボード・タッチ・実ズーム・支援技術・実機を人と確認。状況・版・結果・未確認を記録する。
5. **その後**：完成候補として扱える条件が揃ってから、必要な受け口と設定棚を PWA 側と相談・共同検証。正式登録・配布・公開は別の独立レビューと判断。今回は PWA への連絡や正式カタログ変更はしない。

この資料は参照点を揃えた一次版。未確認項目を空欄のまま持ち越し、調査を深めた結果によって候補・範囲・計画を改める。
