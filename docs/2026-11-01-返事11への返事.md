## 4. 設定の細分化（案・まだ決めていません）

**いきなり 6 役にしない**で、4 段階にしました。`skin.font`（いまの 1 つ）は**残します**。

| 段階 | 設定 | 何が変わるか |
| --- | --- | --- |
| ① `one`（いま） | `skin.font` 1 つ | 何も変わらない |
| ② `pair` | 見出し用＋本文用 | 見出しと本文を分ける（いちばん効く） |
| ③ `roles` | 5 役 | 役ごとに family・太さ・倍率・字間・行間 |
| ④ `digits` | ③＋数字 | スコアの数字だけ別書体 |

```jsonc
{
  "format": "trk-typography", "version": 1,
  "pairing": "shinbun", "base": 16, "scale": "1.25",
  "slots": {
    "display": { "pack": "font-packs/noto-serif-jp.stpack", "family": "TrkNotoSerifJP", "weight": 700,
                 "size": 1.953, "tracking": 0.0, "leading": 1.1 },
    "body":    { "...": "…" }
  }
}
```

- 大きさは**本文を 1 とした倍率**（`倍率³` が題字、`1/倍率` が注記）。倍率を変えると全役が一緒に動きます
- `slots` に無い役は `skin.font` に落ちる（**部分的にだけ**細分化しても壊れない）
- 古いアプリは知らない項目を捨てるだけ（`sanitizeSkinDef` は今もそう）なので、**入れても壊れません**

**こちらで決めなかったこと**：役をどこまで出すか／描画のどこをどの役にするか（`ctx.font` の 20 か所の振り分け）／
`pack.json` の `skin.typography` を書くか（**共有の契約なので、先に書面で合意してから**）／設定画面の UI。
